HTML & CSS Relationship

How structure and style work together

HTML (Structure)

  • Creates basic structure
  • Defines headings, paragraphs, images
  • Provides semantic meaning
  • Plain without styling

CSS (Presentation)

  • Controls visual appearance
  • Adds colors, fonts, layouts
  • Creates responsive designs
  • Enhances user experience

CSS allows developers to separate content from design, resulting in cleaner code and better maintainability.

<!-- HTML provides structure -->
<h1>Welcome</h1>
<p>This is a paragraph</p>

/* CSS provides style */
h1 {
  color: #667eea;
  font-size: 2em;
}

CSS Versions

Evolution of CSS

Version Release Year Key Features
CSS1 1996 Basic styling, font properties, selectors
CSS2 1998 Positioning, z-index, media types
CSS2.1 2011 Color properties (rgba, hsl), box model
CSS3 1999-2015 Flexbox, Grid, animations, transitions
CSS4 Upcoming Container queries, cascade layers

CSS3 introduced modular architecture, allowing features to be developed and released independently.

Types of CSS

Three ways to apply styles

1. Inline CSS

Applied directly to HTML elements using the style attribute

<h1 style="color: red;">Text</h1>

2. Internal CSS

Defined within the HTML document using <style> tags

<style>
h1 { color: blue; }
</style>

3. External CSS

Linked from a separate .css file

<link rel="stylesheet" href="styles.css">

Priority Order: Inline (highest) → Internal → External (lowest)

CSS Selectors

How to target HTML elements

Selector Type Syntax Example
Element tagname p { color: blue; }
ID #idname #header { font-size: 2em; }
Class .classname .button { padding: 10px; }
Universal * * { margin: 0; }
Attribute [attribute] [type="text"] { border: 1px; }
/* Combined selectors */
nav ul li a {
  text-decoration: none;
}
#main .content p:first-child {
  font-weight: bold;
}

Essential CSS Properties

Building blocks of styling

Text Properties

  • color - Text color
  • font-size - Text size
  • font-family - Font type
  • text-align - Alignment
  • line-height - Spacing

Box Properties

  • margin - Outside space
  • padding - Inside space
  • border - Edge styling
  • width/height - Dimensions
  • display - Layout type
/* Box Model Example */

CSS Layout Techniques

Modern layout methods

1. Flexbox

Perfect for one-dimensional layouts

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

2. CSS Grid

Ideal for two-dimensional layouts

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Both Flexbox and Grid are essential for modern responsive design!

Best Practices & Conclusion

Key takeaways for CSS mastery

CSS Best Practices:

  • Use external CSS for better maintainability
  • Follow naming conventions (BEM, SMACSS)
  • Minimize the use of !important
  • Optimize for performance (minify, compress)
  • Use CSS variables for consistency
  • Write mobile-first responsive CSS

Remember: CSS is not just about making things look pretty—it's about creating intuitive, accessible, and performant user experiences.
