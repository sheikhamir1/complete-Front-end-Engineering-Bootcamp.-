📍 Translate - Moving Elements

Position elements anywhere in space

🎯 Basic Syntax

transform: translate(X, Y);

  • X: Horizontal movement (positive = right, negative = left)
  • Y: Vertical movement (positive = down, negative = up)
/* Move 50px right, 100px down */
.element {
  transform: translate(50px, 100px);
}

/* Individual axis movements */
.move-x { transform: translateX(100px); }
.move-y { transform: translateY(50px); }
.move-z { transform: translateZ(30px); }

🔄 Rotate - Spinning Elements

Rotate elements around any axis

📐 Rotation Basics

transform: rotate(angle);

  • Positive degrees: Clockwise rotation
  • Negative degrees: Counter-clockwise rotation
  • Units: deg, rad, turn (1turn = 360deg)
/* 2D Rotation */
.spin { transform: rotate(45deg); }

/* 3D Rotations */
.flip-x { transform: rotateX(180deg); }
.flip-y { transform: rotateY(180deg); }
.spin-z { transform: rotateZ(90deg); }

📏 Scale - Resizing Elements

Grow or shrink elements smoothly

🔍 Scale Values

transform: scale(width, height);

  • 1: Original size (100%)
  • >1: Larger than original
  • <1: Smaller than original
  • 0: Invisible (completely collapsed)
/* Scale both dimensions equally */
.grow { transform: scale(1.5); }

/* Different scales for each axis */
.stretch { transform: scale(2, 0.5); }

/* Individual axis scaling */
.wide { transform: scaleX(2); }
.tall { transform: scaleY(1.5); }

📐 Skew - Tilting Elements

Create slanted, dynamic shapes

🔺 Understanding Skew

transform: skew(X-angle, Y-angle);

  • skewX: Tilt left/right (horizontal distortion)
  • skewY: Tilt up/down (vertical distortion)
  • Angle range: -90deg to 90deg
/* Skew on both axes */
.tilt { transform: skew(20deg, 10deg); }

/* Individual axis skewing */
.lean-right { transform: skewX(20deg); }
.lean-up { transform: skewY(-10deg); }

🔥 Advanced Transform Techniques

Combine transforms and control origin

🔗 Combining Transforms

Chain multiple transform functions:

transform: translate(50px) rotate(45deg) scale(1.2);

/* Complex transformation */
.card:hover {
  transform: translateY(-10px) rotate(5deg) scale(1.05);
  box-shadow: 0 20px 40px rgba(0,0,0,0.3);
}

/* Order matters! */
.example1 { transform: rotate(45deg) translate(50px); }
.example2 { transform: translate(50px) rotate(45deg); }

👁️ Perspective - Creating 3D Depth

Make 3D transforms look realistic

🎯 What is Perspective?

Perspective creates the illusion of depth by making objects farther away appear smaller.

perspective: distance;

  • 500px: Strong 3D effect
  • 1000px: Moderate 3D effect
  • 2000px: Subtle 3D effect
/* Apply perspective to parent */
.container {
  perspective: 800px;
}

/* Or apply to element itself */
.element {
  transform: perspective(800px) rotateY(45deg);
}

✨ CSS Transitions - Smooth Animations

Animate property changes smoothly

🎬 What are Transitions?

Transitions create smooth animations between two states (like hover effects).

Without transition: Instant change ⚡

With transition: Smooth change 🌊

📝 Basic Syntax

transition: property duration timing-function delay;

Component Example What it does
property all, width, color What to animate
duration 0.5s, 1000ms How long it takes
timing-function ease, linear Speed curve
delay 0.2s, 500ms Wait before start
/* Simple transition */
.button {
  transition: background-color 0.3s ease;
}

/* Multiple properties */
.card {
  transition: transform 0.5s, box-shadow 0.3s;
}

/* All properties with delay */
.element {
  transition: all 0.4s ease-in-out 0.1s;
}

⏱️ Timing Functions - Control Animation Speed

Make animations feel natural

🎯 Common Timing Functions

Function Speed Pattern Best For
linear Constant speed Loading bars
ease Slow → Fast → Slow Most animations (default)
ease-in Slow start Elements entering
ease-out Slow end Elements leaving
ease-in-out Slow start & end Attention-grabbing
cubic-bezier() Custom curve Unique effects
/* Custom bounce effect */
.bounce {
  transition: transform 0.6s cubic-bezier(0.68, -0.55, 0.265, 1.55);
}

/* Elastic effect */
.elastic {
  transition: transform 0.8s cubic-bezier(0.175, 0.885, 0.32, 1.275);
}

✅ Best Practices & Tips

Write professional, performant CSS

🚀 Performance Guidelines

Do ✅ Don't ❌
Use transform for animations Animate left/top/margin
Keep transition duration < 1s Make animations too slow
Use will-change for complex animations Overuse will-change
Test on mobile devices Ignore touch interactions
Use GPU-accelerated properties Trigger layout recalculations

🎨 Design Principles

  • Consistency: Use similar timing functions across your site
  • Purpose: Every animation should enhance UX, not distract
  • Accessibility: Respect prefers-reduced-motion
  • Subtlety: Less is often more with animations
/* Respect user preferences */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
