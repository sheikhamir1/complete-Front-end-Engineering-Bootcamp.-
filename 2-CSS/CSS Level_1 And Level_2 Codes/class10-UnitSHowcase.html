Responsive Typography System

This modern layout demonstrates how rem, em, vw, vh, %, ch, and absolute units behave in real-world design.

REM – Global Scalable Typography

Main Heading (2rem)

rem units scale based on the root HTML font size. Change html { font-size } and the entire system scales proportionally. This is how professional design systems handle typography.

EM – Component-Based Scaling

Reusable Card Component

This card uses em units. If the card font-size changes, all internal spacing and text adjust automatically.

VW – Fluid Headings

Resize The Browser

Percentage-Based Layout

This container is 80% width of its parent. Percentage units are ideal for fluid layouts.

Absolute Units (Fixed Size)

200px wide (Fixed pixel size)
5cm wide (Print-based unit)

Absolute units do not respond to screen size changes. Useful for print or controlled output environments.

vmin – Adaptive Shape

This square scales based on the smaller viewport dimension.
