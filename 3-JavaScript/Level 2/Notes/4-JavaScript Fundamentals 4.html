Functions are Values

In JavaScript, a function is not special syntax, it is a value.

Just like:

  • numbers (10)
  • strings ("hello")
  • booleans (true)

A function can:

  • be stored in a variable
  • be copied
  • be passed as an argument
  • be returned from another function

Function Declaration (recap)

This is the syntax you already know:

function sayHi() {
  alert("Hello");
}
This creates a function and stores it in the variable sayHi.

Key points:

  • Function name is required
  • Can be called before it's defined in the code
  • Hoisted to the top of its scope

Function Expression

Another way to create a function is inside an expression.

let sayHi = function() {
  alert("Hello");
};

Here:

  • A function is created
  • It is assigned to a variable
  • The function has no name (anonymous)
This is called a Function Expression.

Why No Function Name?

In Function Expressions, the function name is optional.

let sayHi = function() {
  alert("Hello");
};
The variable sayHi already holds the function, so a name is not required.

Named Function Expression:

let sayHi = function func() {
  alert("Hello");
};

The name "func" is only visible inside the function itself.

Why the Semicolon?

let sayHi = function() {
  alert("Hello");
};

Because this is an assignment statement:

let sayHi = ...;

Just like:

let x = 5;
The semicolon belongs to the assignment, not the function.

Function is a Value

You can even display a function:

function sayHi() {
  alert("Hello");
}

alert(sayHi);
This shows the function's source code, not its result.
No parentheses → function is not executed.

Functions can be compared:

function sayHi() { alert("Hello"); }
function sayHello() { alert("Hello"); }

alert(sayHi === sayHello); // false (different functions)

Copying a Function

Functions can be copied like any other value.

function sayHi() {
  alert("Hello");
}

let func = sayHi;

func();   // Hello
sayHi(); // Hello
Important: 
func = sayHi;   // copy function
func = sayHi(); // ❌ copy result of function

Callback Functions

A callback is a function passed as an argument to another function. 

function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

function showOk() {
  alert("You agreed.");
}

function showCancel() {
  alert("You canceled.");
}

ask("Do you agree?", showOk, showCancel);
showOk and showCancel are callbacks. They are called later, depending on the result.

Anonymous Callback Functions

We can write callbacks directly inside the function call.

ask(
  "Do you agree?",
  function() { alert("You agreed."); },
  function() { alert("You canceled."); }
);

These functions:

  • Have no names
  • Exist only where needed
  • Are very common in JavaScript

Functions Represent Actions

Data:

  • Numbers → data
  • Strings → data
  • Booleans → data

Actions:

  • Functions → actions

A function can be:

  • stored
  • passed around
  • executed later
This is a core JavaScript idea.

Function Declaration vs Function Expression

Function Declaration

function sum(a, b) {
  return a + b;
}

Function Expression

let sum = function(a, b) {
  return a + b;
};
The main difference is when the function is created and how it can be used.

Creation Time Difference (IMPORTANT)

Function Declaration

  • Created before code runs
  • Can be called before it appears in the code
sayHi("John");

function sayHi(name) {
  alert("Hello " + name);
}

✅ Works

Function Expression

  • Created only when execution reaches it
  • Cannot be called earlier
sayHi("John"); // ❌ Error

let sayHi = function(name) {
  alert("Hello " + name);
};

Block Scope Behavior

Function Declarations inside blocks are block-scoped.

❌ This does NOT work:

if (age < 18) {
  function welcome() {
    alert("Hello");
  }
}

welcome(); // Error
In strict mode, this behavior is enforced. In non-strict mode, it may work in some browsers but shouldn't be relied upon.

Correct Way: Function Expression

Declare variable outside, assign function conditionally.

let welcome;

if (age < 18) {
  welcome = function() {
    alert("Hello");
  };
} else {
  welcome = function() {
    alert("Greetings");
  };
}

welcome(); // Works

Or shorter using ? :

let welcome = (age < 18)
  ? function() { alert("Hello"); }
  : function() { alert("Greetings"); };

When to Use Which?

Prefer Function Declaration when:

  • Function is always needed
  • Readability matters
  • You want to call it anywhere

Use Function Expression when:

  • Function depends on conditions
  • Function is used as a value
  • You pass it as a callback
  • You need block-level control
Default choice → Function Declaration
Use Function Expression when declarations don't fit

Arrow Functions – The Basics

Arrow functions are a shorter and concise way to write functions, often replacing Function Expressions.

Syntax

let func = (arg1, arg2, ..., argN) => expression;

This is equivalent to:

let func = function(arg1, arg2, ..., argN) {
  return expression;
};

Example – simple arrow function

let sum = (a, b) => a + b;
alert(sum(1, 2)); // 3

Arrow Function Variations

Single argument (no parentheses needed)

let double = n => n * 2;
alert(double(3)); // 6

No arguments (empty parentheses)

let sayHi = () => alert("Hello!");
sayHi();

Conditional arrow functions

let age = prompt("What is your age?", 18);

let welcome = (age < 18) ? 
  () => alert("Hello!") : 
  () => alert("Greetings!");

welcome();

Multiline Arrow Functions

For multiple statements, use curly braces { ... } and explicit return: 

let sum = (a, b) => {
  let result = a + b;
  return result;
};

alert(sum(1, 2)); // 3

Arrow Functions Summary

  • One-liner: (...args) => expression → returns the expression automatically
  • Multiline: (...args) => { body } → use return to return a value
  • Can omit parentheses for single arguments
  • Can be used anywhere Function Expressions are used

When to Use Arrow Functions

Arrow functions are ideal for:

  • Short, simple actions
  • Callbacks
  • Situations where brevity improves readability

Example with array methods:

let numbers = [1, 2, 3, 4, 5];

// Traditional function
let doubled = numbers.map(function(x) {
  return x * 2;
});

// Arrow function (shorter)
let doubled2 = numbers.map(x => x * 2);

JavaScript Specials – Code Structure

Statements

  • Usually end with ; (semicolon)
  • Line breaks often act as delimiters (automatic semicolon insertion)
  • Extra semicolons are ignored
  • No semicolons needed after code blocks { ... } or loops

Strict Mode

'use strict';
  • Enables modern JavaScript features
  • Helps avoid old-fashioned behaviors
  • Should be at the top of the script or function

Variables

Variable Types

  • let → block-scoped variable
  • const → constant, cannot be changed
  • var → old-style, function-scoped

Rules:

  • Start with letters, $ or _ (cannot start with digit)
  • Can store any type (dynamic typing)

Examples:

let name = "John";
const age = 25;
var oldStyle = "avoid this";

Data Types

Primitive Types

  • number → numbers
  • bigint → large integers
  • string → text
  • boolean → true/false
  • null → "empty"
  • undefined → not assigned

Complex Types

  • object → complex structures
  • symbol → unique identifiers
typeof returns the type (typeof null is a special exception → "object")

Operators and Loops

Operators

  • Arithmetic: + - * / % **
  • Assignment: =, +=, -=, *= ...
  • Logical: &&, ||, ! → short-circuit evaluation
  • Conditional: cond ? resultA : resultB
  • Nullish coalescing: ?? → chooses defined value

Loops

  • while (condition) { ... }
  • do { ... } while (condition)
  • for(let i=0; i<10; i++) { ... }
  • break/continue to control iterations
Variables declared with let are block-scoped

Functions Recap

Three ways to create functions:

Function Declaration

function sum(a, b) {
  return a + b;
}

Function Expression

let sum = function(a, b) {
  return a + b;
};

Arrow Function

let sum = (a, b) => a + b;
let sum = (a, b) => { return a + b; };
let sayHi = () => alert("Hello");
let double = n => n * 2;

Key Points:

  • Local variables → visible only inside function
  • Parameters can have default values
  • Functions always return something, undefined if no return
