JavaScript Objects

Properties, Methods, and Memory Management

Object Basics

Objects are used to store keyed collections of various data and more complex entities. In JavaScript, objects penetrate almost every aspect of the language.

Key Concepts

  • Objects store properties (key-value pairs)
  • Properties can be accessed using dot notation or square brackets
  • Objects are assigned and copied by reference, not by value
  • Objects can contain primitive values, other objects, or functions

Object Creation and Properties

Objects can be created using two syntaxes:

let user = new Object(); // "object constructor" syntax
let user = {};  // "object literal" syntax

Property Access

Properties can be accessed using:

  • Dot notation: user.name
  • Square brackets: user["name"]

Computed Properties and Methods

Computed properties allow property names to be determined at runtime: 

let fruit = prompt("Which fruit to buy?", "apple");

let bag = {
  [fruit]: 5 // the name of the property is taken from the variable fruit
};

alert( bag.apple ); // 5 if fruit="apple"

Property Shorthand

When property names match variable names, you can use shorthand: 

function makeUser(name, age) {
  return {
    name, // same as name:name
    age, // same as age:age
    // ...
  };
}

Property Names and Limitations

Property names have certain limitations:

Key Points

  • Property keys must be strings or symbols
  • Special property __proto__ has unique behavior
  • Reserved words can be used as property names
  • Non-integer property names are listed in creation order

Integer properties (like "49") are sorted before non-integer properties in for..in loops.

The "in" Operator and for..in Loop

The "in" operator checks if a property exists in an object:

let user = { name: "John", age: 30 };

alert( "age" in user ); // true
alert( "blabla" in user ); // false

for..in Loop

To iterate over all keys of an object:

let user = {
  name: "John",
  age: 30,
  isAdmin: true
};

for (let key in user) {
  // keys
  alert( key);  // name, age, isAdmin
  // values for the keys
  alert( user[key] ); // John, 30, true
}

Object References and Copying

Objects are stored and copied "by reference", not by value:

Reference Equality

Two variables are equal only if they reference the same object: 

let a = {};
let b = a; // copy the reference

alert( a === b ); // true
alert( a === b ); // true

Const objects can still have their properties modified, even though the object reference itself is constant.

Object Cloning and Merging

There are several ways to clone objects:

Object.assign()

Copies all enumerable properties from source objects to a target object: 

let user = { name: "John", age: 30 };

let clone = Object.assign({}, user);

alert(clone.name); // John
alert(clone.age); // 30

Spread Syntax (ES6+)

Creates a new object with properties from the original:

let user = { name: "John", age: 30 };

let clone = {...user}; // same as Object.assign({}, user)

structuredClone()

Creates a deep copy of an object, including nested properties: 

let user = {
  name: "John",
  sizes: {
    height: 182,
    width: 50
  }
};

let clone = structuredClone(user);

// user and clone are now completely separate objects
clone.sizes.width = 60;
alert(user.sizes.width); // 50 (unchanged)
alert(clone.sizes.width); // 60

Garbage Collection

JavaScript automatically manages memory through garbage collection:

Reachability

An object is reachable if it can be accessed from a root (like a global variable or the current function).

Garbage Collection Process

  • Mark phase: The garbage collector identifies all reachable objects starting from the roots.
  • Sweep phase: It removes all objects that are not marked as reachable.
  • Optimizations: Engines use various strategies like generational, incremental, and idle-time collection.

Let Us Sum Up

Objects are the cornerstone of JavaScript's data structure system, providing a flexible way to organize and manage complex data.

Key Takeaways

  • Objects store key-value pairs of various data types
  • Properties can be accessed using dot notation or square brackets
  • Objects are passed by reference, not by value
  • Objects can have computed properties and methods
  • Memory management is handled automatically through garbage collection

Understanding objects is fundamental to JavaScript programming and provides the foundation for more complex data structures and design patterns.

Key Words

Object

A collection of key-value pairs that allows for structured data organization and complex entity representation.

Property

A key in an object that maps to a value, which can be any JavaScript data type.

Method

A function that is a property of an object, which can access and manipulate the object's data.

Reference

The memory address where an object is stored, allowing multiple variables to point to the same object.

Garbage Collection

The automatic process of freeing up memory that is no longer reachable, performed by the JavaScript engine.

Deep Cloning

Creating a new object with the same properties as an existing object, including all nested properties.

Shallow Cloning

Creating a new object that copies the top-level properties of an existing object, but nested objects are still shared by reference.
