Operators: Basic Idea

Operators perform actions on values (operands).

Unary → one operand

let x = 1;
x = -x; // unary minus

Binary → two operands

let y = 3;
y - x; // binary minus

Math Operators

JavaScript supports standard math:

+ - * / % **

Remainder %

Returns what's left after division.

5 % 2; // 1
8 % 4; // 0

Exponentiation **

Power operation.

2 ** 3;      // 8
4 ** 0.5;    // 2 (square root)

+ with Strings (Important!)

+ adds numbers, but joins strings.

"1" + 2;   // "12"
2 + 2 + "1"; // "41"
"1" + 2 + 2; // "122"
Other operators always convert to numbers:
"6" - "2"; // 4
"6" / "2"; // 3

Unary Plus + (Type Conversion)

Unary + converts values to numbers.

+"2";    // 2
+true;   // 1
+"";     // 0

Useful when adding user input:

let apples = "2";
let oranges = "3";

+apples + +oranges; // 5

Operator Precedence

Operators run by priority.

1 + 2 * 2;     // 5
(1 + 2) * 2;   // 6
Unary operators run before binary ones.

Example:

let x = 1;
let y = 2;
let z = 3;

x + y * z;    // 7 (multiplication first)
(x + y) * z;  // 9 (parentheses first)

Assignment =

Assignment is an operator and returns a value.

let a, b;
a = b = 4; // both become 4
Avoid clever tricks—clarity is better.

Chained assignment:

let a, b, c;
a = b = c = 2 + 2;
alert(a); // 4
alert(b); // 4
alert(c); // 4

Modify-in-place Operators

Short forms for updating variables:

let n = 2;
n += 5; // 7 (same as n = n + 5)
n *= 2; // 14 (same as n = n * 2)

All modify-in-place operators:

+=  -=  *=  /=  %=  **=
These operators are more concise and often more readable.

Increment / Decrement

Increase or decrease by 1.

counter++; // postfix
++counter; // prefix

Difference:

let c = 1;
c++;   // returns 1, then becomes 2
++c;   // becomes 3, returns 3
Use prefix when you need the new value.

Bitwise Operators (Rare)

Work on binary numbers (& | ^ << >>).

Common bitwise operators:

&   // AND
|   // OR
^   // XOR
~   // NOT
<<  // Left shift
>>  // Right shift
>>> // Zero-fill right shift
Used in special cases (e.g., cryptography), not common in web dev.

Comma Operator ,

Evaluates multiple expressions, returns the last one.

let a = (1 + 2, 3 + 4);
a; // 7
Rarely improves readability—use carefully.

Common use in loops:

for (let i = 0, j = 10; i < 10; i++, j--) {
  console.log(i, j);
}

Key Takeaways

  • % → remainder, ** → power
  • + concatenates strings but adds numbers
  • Unary + converts to number
  • Use parentheses to control order
  • Prefer clear, readable code over clever shortcuts
Understanding operator precedence is crucial for writing bug-free code.

Comparison Operators

JavaScript supports standard math-style comparisons:

  • Greater / less: >, <
  • Greater / less or equal: >=, <=
  • Equal: ==
  • Not equal: !=
  • Strict equal: ===
  • Strict not equal: !==

All comparison operators return a boolean (true or false).

2 > 1;    // true
2 == 1;   // false
2 != 1;   // true

String Comparison

Strings are compared character by character using Unicode order (not real dictionary order). 

'Z' > 'A';        // true
'Glow' > 'Glee'; // true
'Bee' > 'Be';    // true
Notes:
  • Comparison is case-sensitive
  • Lowercase letters are greater than uppercase ('a' > 'A')

Comparing Different Types

When types differ, JavaScript converts values to numbers (except with strict equality). 

'2' > 1;     // true
'01' == 1;   // true
true == 1;   // true
false == 0;  // true
This can cause confusing results:
0 == false;   // true
'' == false;  // true

Strict Equality (===)

Strict equality checks value AND type. No type conversion happens. 

0 === false; // false
null === undefined; // false
Best practice: Use === and !== instead of == and !=.

Examples:

0 == false;    // true
0 === false;   // false

'' == false;   // true
'' === false;  // false

null and undefined Quirks

Special and often confusing behavior:

Equality

null == undefined;   // true
null === undefined;  // false

They don't equal anything else.

Comparisons (< > <= >=)

null → 0
undefined → NaN

null >= 0; // true
null > 0;  // false
null == 0; // false

undefined > 0;  // false
undefined < 0;  // false
undefined == 0; // false
Avoid comparisons with null / undefined.

Conditional Branching: if

The if statement runs code when a condition is truthy.

if (year == 2015) {
  alert("Correct!");
}

Falsy values

  • 0
  • ""
  • null
  • undefined
  • NaN

Truthy values

Everything else

else and else if

if (year < 2015) {
  alert("Too early");
} else if (year > 2015) {
  alert("Too late");
} else {
  alert("Exactly!");
}

Logical Operators Overview

JavaScript has four logical operators:

  • || → OR
  • && → AND
  • ! → NOT
  • ?? → Nullish coalescing
Logical operators do not work only with booleans. They can return any value, not just true or false.

OR operator ||

Returns true if any operand is truthy.

true || false;   // true
false || false; // false

OR returns the first truthy value:

1 || 0;                 // 1
null || "hello";        // "hello"
undefined || null || 0; // 0
