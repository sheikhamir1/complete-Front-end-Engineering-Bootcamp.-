Running JavaScript

JavaScript can run in the browser (using HTML) or on the server (e.g., Node.js).

Browser

Use the <script> tag in HTML

<script>
  alert("Hello, world!");
</script>

Node.js

Run from command line

node file.js

<script> Tag Basics

  • JavaScript is placed inside <script>
  • Old attributes like type and language are no longer needed
  • Code runs automatically when the browser reads the tag
<!-- Modern approach -->
<script>
  // JavaScript code here
  console.log("Hello, JavaScript!");
</script>

External Scripts

For larger code, use a separate file.

<script src="script.js"></script>

Benefits

  • Cleaner HTML
  • Faster loading (browser caching)
  • Better code organization
  • Reusability across pages
Important: If src is used, any code inside the tag is ignored.

Code Structure

  • JavaScript code is made of statements
  • Statements usually end with a semicolon ;
alert("Hello");
alert("World");
JavaScript can insert semicolons automatically, but this can cause errors, so using semicolons is safer.

Comments

Comments explain code and are ignored by JavaScript.

Single-line

// This is a comment
let x = 5; // Inline comment

Multi-line

/* This is
   a multi-line
   comment */
Important: Nested comments are not allowed in JavaScript.

Strict Mode ("use strict")

Strict mode enables modern, safer JavaScript behavior.

  • Must be at the top of the file
  • Cannot be turned off once enabled
  • Helps catch common coding mistakes
"use strict";

// This will cause an error in strict mode
message = "Hello"; // ReferenceError: message is not defined

// In strict mode, you must declare variables first
let message = "Hello"; // This works

Variables (Storing Data)

Variables are named containers for data like user names, messages, or numbers. 

// Declare a variable (modern way)
let message = "Hello";
alert(message);

// You can change its value
message = "World";
A variable must be declared once. Redeclaring with let causes an error.

let, var, and const

let - Modern, recommended

  • Block-scoped
  • Can be reassigned
  • Cannot be redeclared
let age = 25;
age = 30; // OK

var - Old-style, avoid

  • Function-scoped
  • Can be reassigned
  • Can be redeclared
var age = 25;
var age = 30; // OK (but bad practice)

const - Value cannot be changed

const PI = 3.14;
// PI = 4; // TypeError: Assignment to constant variable

Uppercase constants are used for fixed, known values:

const COLOR_RED = "#F00";

Variable Naming Rules

Allowed

  • Letters, digits, $, _
  • Case-sensitive (apple ≠ APPLE)
let userName;
let shopping_cart;
let $element;
let _privateVar;

Not Allowed

  • Cannot start with a digit
  • Cannot use hyphens
let 1user;     // ❌
let my-name;  // ❌
Use clear, descriptive names—they make code easier to understand and debug.

Strict Mode and Variables

In strict mode, variables must be declared before use.

With Strict Mode

"use strict";
num = 5; // ❌ ReferenceError

JavaScript prevents accidental global variables.

Without Strict Mode

num = 5; // Works, but avoid

Creates a global variable unintentionally (bad practice).

Data Types (Overview)

JavaScript is dynamically typed: a variable can change its type.

let x = "hello"; // string
x = 42;          // number (no error)

Primitive Types (7)

number

123, 12.5, Infinity, NaN

bigint

Very large integers

const big = 12345678901234567890n;

string

Text

let name = "John";
let msg = `Hello, ${name}`;

boolean

true, false

null

Known empty/unknown value

undefined

Not assigned

Non-primitive Type (1)

object

Collections and complex data

Special Values

NaN - Not a Number

Invalid math result

"abc" / 2; // NaN
typeof NaN; // "number"

NaN is the only value that is not equal to itself:

NaN === NaN; // false

null - Intentional "no value"

Represents the intentional absence of any object value

let user = null;
// user is explicitly set to no value

undefined - Not assigned

A variable that has been declared but not assigned a value

let x;
console.log(x); // undefined

// Difference between null and undefined
let user = null;      // Explicitly set to no value
let admin;            // Declared but not assigned

typeof Operator

Used to check a value's type.

typeof 123;        // "number"
typeof "hi";       // "string"
typeof true;       // "boolean"
typeof null;       // "object" ❗ (language bug)
typeof alert;      // "function"
Known Bug: typeof null returns "object" instead of "null". This is a historical JavaScript bug that can't be fixed without breaking existing code.

Key Takeaways

Variable Declaration

  • Use let for variables that will change
  • Use const for fixed values
  • Avoid var in modern code

Variable Rules

  • Always declare variables (especially in strict mode)
  • Use clear, descriptive names
  • Follow naming conventions (camelCase for variables)

Data Types

  • JavaScript has 8 data types (7 primitive + object)
  • Use typeof to check a value's type
  • Be aware of special values like NaN, null, and undefined

User Interaction in the Browser

JavaScript provides three simple browser functions to interact with users. They are modal, meaning they pause the page until the user responds.

alert

Shows a message and waits for OK.

alert("Hello!");

Used to display information.

prompt

Asks the user for input.

let age = prompt("How old are you?", 18);
alert(age);
  • Returns text if OK is pressed
  • Returns null if Cancel or Esc is pressed
  • Always give a default value ("") for better compatibility

confirm

Asks a yes/no question.

let isAdmin = confirm("Are you an admin?");
alert(isAdmin);
  • Returns true → OK
  • Returns false → Cancel / Esc

Type Conversions (Basics)

JavaScript often converts values automatically, but we can also do it explicitly.

String conversion

Used when showing values.

let value = true;
value = String(value); // "true"

Numeric conversion

Used in math operations or when reading input.

let num = Number("123"); // 123

// Invalid numbers become NaN:
Number("abc"); // NaN

Important rules:

  • null → 0
  • undefined → NaN
  • true → 1, false → 0
  • " 123 " → 123
  • "123z" → NaN

Boolean conversion

Used in conditions.

Boolean(1);      // true
Boolean(0);      // false
Boolean("hi");   // true
Boolean("");     // false
"0" and " " are true (non-empty strings).

Key Takeaways

User Interaction

  • alert → show message
  • prompt → get text input (string or null)
  • confirm → get yes/no (true / false)

Type Conversion Rules

  • String → String(value)
  • Number → Number(value)
  • Boolean → Boolean(value)

Common Mistakes

  • undefined becomes NaN, not 0
  • "0" is true, not false
  • Forgetting that prompt returns a string
Always validate user input from prompt() and convert it to the appropriate type before using it in calculations.
