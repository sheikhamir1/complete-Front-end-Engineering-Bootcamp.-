Actions in Markup & Behavior Pattern

1. Actions in Markup (data-action)

Each button has a data-action attribute. Instead of attaching separate click handlers to every button, only the parent div listens for clicks.

Click any button above...

2. Behavior Pattern - Counter

Every button having data-counter automatically increases its own value when clicked.

3. Behavior Pattern - Toggle

The button contains data-toggle-id. When clicked, JavaScript finds the element with that ID and toggles its visibility.
