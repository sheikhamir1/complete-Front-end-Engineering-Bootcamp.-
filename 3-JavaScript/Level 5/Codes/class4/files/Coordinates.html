Coordinate Systems

The browser actually uses two coordinate systems.

Coordinate System Used By Description
Window Coordinates position:fixed Measured from the visible browser window. Changes while scrolling.
Document Coordinates position:absolute Measured from the top of the complete webpage. Never changes because of scrolling.

JavaScript Properties

  • clientX → Mouse X inside viewport
  • clientY → Mouse Y inside viewport
  • pageX → Mouse X inside entire webpage
  • pageY → Mouse Y inside entire webpage
  • window.scrollY → Current vertical scroll
  • window.scrollX → Current horizontal scroll
  • element.getBoundingClientRect()
