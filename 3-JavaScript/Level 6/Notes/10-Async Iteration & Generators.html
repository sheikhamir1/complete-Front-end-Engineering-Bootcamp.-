Async Iteration & Generators

Handling data streams that arrive over time

Asynchronous iteration allows us to iterate over data that comes asynchronously, on-demand. For example, downloading data chunk-by-chunk over a network. Async generators make this incredibly convenient.

Real-World Analogy: Streaming a Movie 🎬
A regular iterator is like a downloaded movie file: all the data is there, you just go through it. An async iterator is like Netflix streaming: you only get the next chunk of data (the next second of video) when the network delivers it. You must await the next piece.

Recall: Regular Iterables

How we loop through synchronous data

To make an object iterable using for..of, we add a method named Symbol.iterator that returns an object with a next() method.

Standard Iterable Range

let range = {
  from: 1,
  to: 5,

  [Symbol.iterator]() {
    return {
      current: this.from,
      last: this.to,
      next() {
        if (this.current <= this.last) {
          return { done: false, value: this.current++ };
        } else {
          return { done: true };
        }
      }
    };
  }
};

for(let value of range) {
  alert(value); // 1, 2, 3, 4, 5 instantly
}
The Limitation: The next() method must return the value immediately. If the value takes time to generate (like a network request), regular iterables can't pause and wait.

Async Iterables

Looping through data that arrives asynchronously

To make an object asynchronously iterable, we use Symbol.asyncIterator, make next() an async function, and loop using for await..of.

Async Iterable Range (1 value per second)

let range = {
  from: 1,
  to: 5,

  [Symbol.asyncIterator]() { // (1)
    return {
      current: this.from,
      last: this.to,

      async next() { // (2)
        await new Promise(resolve => setTimeout(resolve, 1000)); // (3)

        if (this.current <= this.last) {
          return { done: false, value: this.current++ };
        } else {
          return { done: true };
        }
      }
    };
  }
};

(async () => {
  for await (let value of range) { // (4)
    alert(value); // 1, 2, 3, 4, 5 (with 1s delay)
  }
})();

Sync vs. Async Iterables

Understanding the key differences

Feature Regular Iterable Async Iterable
Object Method Symbol.iterator Symbol.asyncIterator
next() returns... {value, done} immediately A Promise that resolves to {value, done}
Loop Syntax for (let x of iterable) for await (let x of iterable)

Spread syntax doesn't work!

Features that require synchronous iterators (like [...range]) don't work with async iterables. They look for Symbol.iterator, not Symbol.asyncIterator.

Recall: Regular Generators

The shortcut for making iterables

Instead of writing a complex Symbol.iterator method manually, we can use a generator function function* to make objects iterable much more cleanly.

Using a Generator for Iteration

let range = {
  from: 1,
  to: 5,

  *[Symbol.iterator]() {
    for(let value = this.from; value <= this.to; value++) {
      yield value;
    }
  }
};

for(let value of range) {
  alert(value); // 1, 2, 3, 4, 5
}
The Problem: In regular generators, we can't use await. All values must come synchronously. What if we need to await a network request inside the generator?

Async Generators

Combining generators with asynchronous code

For practical applications, when we want an object that generates values asynchronously, we use an async generator. Just prepend function* with async!

Syntax: async function*

async function* generateSequence(start, end) {
  for (let i = start; i <= end; i++) {
    // We can use await inside!
    await new Promise(resolve => setTimeout(resolve, 1000));
    yield i;
  }
}

(async () => {
  let generator = generateSequence(1, 5);
  for await (let value of generator) {
    alert(value); // 1, 2, 3, 4, 5 (1 second apart)
  }
})();
How it works: In an async generator, generator.next() is asynchronous—it returns a Promise. That's why it works perfectly with for await...of.

Async Iterable Range (Simplified)

Using async generators as Symbol.asyncIterator

Just like regular generators can be used as Symbol.iterator, async generators can be used as Symbol.asyncIterator to make objects asynchronously iterable.

Clean, modern implementation

let range = {
  from: 1,
  to: 5,

  async *[Symbol.asyncIterator]() {
    for(let value = this.from; value <= this.to; value++) {
      await new Promise(resolve => setTimeout(resolve, 1000));
      yield value;
    }
  }
};

(async () => {
  for await (let value of range) {
    alert(value); // 1, 2, 3, 4, 5 (with pauses)
  }
})();

Real-Life Example: Paginated Data

Fetching commits from GitHub page-by-page

Many APIs return data in "pages". GitHub gives 30 commits per request, plus a URL for the next page. Async generators make this seamless!

The Async Generator

async function* fetchCommits(repo) {
  let url = `https://api.github.com/repos/${repo}/commits`;

  while (url) {
    const response = await fetch(url);
    const body = await response.json();

    // Get next page URL from the Link header
    let nextPage = response.headers.get('Link')
      .match(/<(.*?)>; rel="next"/)?.[1];
    
    url = nextPage;

    // Yield commits one by one
    for(let commit of body) {
      yield commit;
    }
  }
}
Analogy: Reading an Encyclopedia 📚
Instead of carrying 10 heavy volumes home at once, you use an async generator. You ask for Volume 1 (network request). When it arrives, you read it (yield the pages). Then you ask for Volume 2, and so on. The pagination is invisible to the user!

Summary

Key differences to remember

Feature Synchronous Asynchronous
Iterator Method Symbol.iterator Symbol.asyncIterator
Generator Declaration function* async function*
next() returns {value, done} Promise resolving to {value, done}
Loop Syntax for (let x of obj) for await (let x of obj)
When to use: Use regular iterators/generators for data that's instantly available. Use async iterators/generators when data arrives with delays (network requests, file streams, database pagination).
