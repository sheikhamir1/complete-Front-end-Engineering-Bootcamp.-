Number Type 🔢

Basic Number Type

Represents integers and floating point numbers

Supports math operations: + - * /

let n = 123;
let pi = 3.14;
let sum = 5 + 7; // 12

Special Numeric Values

Infinity

Greater than any number

alert( 1 / 0 ); // Infinity
alert( Infinity ); // Infinity
NaN

Result of incorrect math operation

alert( "not a number" / 2 ); // NaN
alert( NaN + 1 ); // NaN

BigInt Type 🔢

What is BigInt?

For integers of arbitrary length

Created by appending n to an integer

Used for cryptography or precision timestamps

const bigInt = 1234567890123456789012345678901234567890n;

Why BigInt?

Number Type Limitation

Regular numbers are limited to ±(253-1)

// Both show same result (precision error)
console.log(9007199254740991 + 1); // 9007199254740992
console.log(9007199254740991 + 2); // 9007199254740992

BigInt solves this by storing exact values of any size

String Type 📝

String Basics

Represents textual data

Must be surrounded by quotes

No separate character type in JavaScript

let str = "Hello";
let str2 = 'Single quotes';
let phrase = `Backticks`;

Types of Quotes

Double & Single Quotes

Simple quotes, practically no difference

let double = "Hello";
let single = 'World';
Backticks

Extended functionality with ${...}

let name = "John";
alert( `Hello, ${name}!` ); // Hello, John!

Boolean Type ✅

Boolean Basics

Only two values: true and false

Used for yes/no values

true means "yes, correct"

false means "no, incorrect"

let nameFieldChecked = true;
let ageFieldChecked = false;

Boolean from Comparisons

Comparison Results

Comparisons return boolean values

let isGreater = 4 > 1;
alert( isGreater ); // true

let isEqual = 5 === 5;
alert( isEqual ); // true

Essential for conditional logic and control flow

Null and Undefined Types ⭕❓

Null Type ⭕

Special value meaning "nothing" or "empty"

Represents "value unknown"

Forms a separate type of its own

let age = null;
// age is unknown or empty

Undefined Type ❓

Means "value is not assigned"

Default value for unassigned variables

Also forms a separate type of its own

let age;
alert(age); // "undefined"

let name = undefined; // Not recommended

Objects and Symbols 📦🔑

Object Type 📦

Non-primitive data type

Used to store collections of data

Can contain multiple values and complex entities

let user = {
  name: "John",
  age: 30
};

Symbol Type 🔑

Used to create unique identifiers for objects

Values are guaranteed to be unique

Often used as object property keys

let id = Symbol("id");
let user = {
  [id]: 123
};

The typeof Operator 🔍

What is typeof?

Returns the type of the operand

Useful for processing different types

Returns a string with the type name

typeof undefined // "undefined"
typeof 0 // "number"
typeof true // "boolean"
typeof "foo" // "string"

Special Cases

typeof null

Returns "object" (official error)

typeof null // "object"
// This is a language error!
typeof functions

Returns "function" (convenience)

typeof alert // "function"
// Functions are technically objects

Summary 📝

Primitive Types
  • number - integers & floats
  • bigint - large integers
  • string - text data
  • boolean - true/false
  • null - empty value
  • undefined - unassigned value
  • symbol - unique identifiers
Non-Primitive Type
  • object - collections of data
  • Used for complex data structures
  • Can contain multiple values
  • Functions are technically objects
typeof Operator
  • Returns the type of a value
  • Useful for type checking
  • Special case: typeof null is "object"
  • Convenience: typeof function is "function"
Key Takeaways
  • JavaScript is dynamically typed
  • Variables can change types
  • 8 basic data types total
  • Use typeof to check types

Understanding data types is fundamental to writing effective JavaScript code. Each type has its specific use cases and behaviors.
