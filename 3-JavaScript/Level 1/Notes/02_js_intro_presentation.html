An Introduction to JavaScript

Let's explore what makes JavaScript so special and discover what we can achieve with this powerful language
From making web pages alive to powering servers and mobile apps

🚀 What is JavaScript?

JavaScript was initially created to "make web pages alive".

The programs in this language are called scripts that can be written directly in HTML and run automatically as the page loads.

✨ Scripts are provided and executed as plain text
⚡ No special preparation or compilation needed
🌐 Very different from Java despite the similar name

🤔 Why is it called JavaScript?

Originally named "LiveScript", it was renamed to JavaScript to position it as a "younger brother" of the popular Java language.

However, JavaScript evolved into a fully independent language with its own specification called ECMAScript.

JavaScript now has NO relation to Java at all!

🔧 How Do Engines Work?

1

Parse

The engine reads and parses the script

2

Compile

Converts the script to machine code

3

Execute

Machine code runs fast with optimizations

The engine continuously optimizes the code by analyzing data flow and improving performance!

✨ What Can In-Browser JavaScript Do?

🎨 Add new HTML, change content, modify styles
👆 React to user actions (clicks, movements, key presses)
🌐 Send network requests, download/upload files (AJAX)
🍪 Get and set cookies, show messages to users
💾 Remember data on client-side (local storage)

🔒 What CAN'T JavaScript Do?

JavaScript's abilities are limited for security to protect users:

🚫 Cannot read/write arbitrary files on hard disk
🚫 No direct access to OS functions
🚫 Limited access to camera/microphone (requires permission)
🚫 Cannot access other tabs/windows from different domains

This is the "Same Origin Policy" - protecting user safety!

🌟 What Makes JavaScript Unique?

Full Integration

Complete integration with HTML/CSS

Simplicity

Simple things are done simply

Universal Support

Supported by all major browsers by default

JavaScript is the only browser technology that combines all three!

🔄 Languages "Over" JavaScript

Many languages transpile (convert) to JavaScript:

CoffeeScript

Dart

Kotlin
