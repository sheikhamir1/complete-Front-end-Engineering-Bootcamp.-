The language itself

  • Environment: Browser is ideal for online learning

Note

📝 The <script> Tag

Adding JavaScript to HTML

JavaScript programs can be inserted anywhere in HTML using the <script> tag. 

<!DOCTYPE HTML>
<html>
<body>
  <p>Before the script...</p>
  <script>
    alert('Hello, world!');
  </script>
  <p>...After the script.</p>
</body>
</html>

Code executes automatically when the browser processes the tag.

⚙️ Modern Markup - Type Attribute

Evolution of script attributes

  • Old Standard (HTML4): Required type="text/javascript"
  • Current Status: No longer required
  • Modern Usage: Now used for JavaScript modules
Advanced Topic

We'll explore JavaScript modules in a later part of the tutorial.

🌐 Modern Markup - Language Attribute

Outdated attribute

  • Purpose: Originally meant to specify the script language
  • Current Status: No longer necessary
  • Reason: JavaScript is the default and standard language

Recommendation: Avoid using this attribute in modern code

🏺 Modern Markup - Ancient Comments

Historical JavaScript patterns

In really old code, you might find:

<script type="text/javascript"><!--
    ...
//--></script>
  • Purpose: Hide JavaScript from old browsers that didn't understand <script>
  • Current Status: Not needed in modern JavaScript
  • Indicator: Helps identify really old code

📁 External Scripts

Separating JavaScript code

For larger JavaScript code, use separate files with the src attribute: 

<script src="/path/to/script.js"></script>

Path Options:

  • Absolute path: src="/path/to/script.js"
  • Relative path: src="script.js" or src="./script.js"
  • Full URL: src="https://cdnjs.cloudflare.com/.../lodash.js"

📚 Multiple Scripts & Best Practices

Organizing your code

Multiple Scripts: Use multiple <script> tags 

<script src="/js/script1.js"></script>
<script src="/js/script2.js"></script>

Best Practices:

  • Simple scripts in HTML, complex ones in separate files
  • Browser caches external files for better performance
  • Reduces traffic and makes pages faster

⚠️ Important Notes

Critical rules to remember

Critical Rule: A single <script> tag cannot have both src attribute and internal code 

<!-- This won't work -->
<script src="file.js">
  alert(1); // This content is ignored
</script>

Correct Approach:

<script src="file.js"></script>
<script>
  alert(1);
</script>
