Variables in Functions 🔄

Local Variables

function showMessage() {
  let message = "Hello, I'm JavaScript!";
  alert(message);
}

showMessage(); // Shows the message
alert(message); // Error! Variable not found
Declared inside the function
Only visible within the function
Destroyed when function completes

Outer Variables

let userName = 'John';

function showMessage() {
  let message = 'Hello, ' + userName;
  alert(message);
}

showMessage(); // Hello, John
Declared outside the function
Accessible inside the function
Can be modified by the function

Variable Shadowing 

let userName = 'John';

function showMessage() {
  let userName = "Bob"; // Local variable
  let message = 'Hello, ' + userName; // Bob
  alert(message);
}

showMessage(); // Shows "Hello, Bob"
alert(userName); // Still "John"

Key Point: A local variable with the same name as an outer variable "shadows" the outer variable inside the function.

Parameters & Defaults 📊

Parameters

function showMessage(from, text) {
  alert(from + ': ' + text);
}

showMessage('Ann', 'Hello!'); // Ann: Hello!
showMessage('Ann', "What's up?");
Values passed to function
Act as local variables
Copied from arguments

Default Values

function showMessage(from, text = "no text") {
  alert(from + ": " + text);
}

showMessage("Ann"); // Ann: no text
showMessage("Ann", "Hi!"); // Ann: Hi!
Used when argument not provided
Can be expressions
Evaluated only when needed

Default Value Techniques

Modern JavaScript

function func(a = 5) {
  // ...
}

Old School

function func(a) {
  a = a || 5;
  // ...
}

Nullish Coalescing

function func(a) {
  a = a ?? 5;
  // ...
}

Pro Tip: Use nullish coalescing (??) when you want to distinguish between null/undefined and other falsy values like 0 or "".

Returning Values ↩️

Return Statement

function sum(a, b) {
  return a + b;
}

let result = sum(1, 2);
alert(result); // 3
return keyword exits function
Sends value back to caller
Can be anywhere in function

Multiple Returns

function checkAge(age) {
  if (age >= 18) {
    return true;
  } else {
    return confirm('Parents permission?');
  }
}

if (checkAge(age)) {
  alert('Access granted');
} else {
  alert('Access denied');
}
Multiple return statements
Function exits at first return

Return Best Practices

Good Practice 

function sum(a, b) {
  return (
    a + b
  );
}

Start return value on same line as return keyword

Common Mistake 

function sum(a, b) {
  return
    a + b; // Never executed!
}

JavaScript inserts semicolon after return

Remember: A function without a return statement returns undefined. Empty return also returns undefined.

Naming Conventions

Checks permission

One Function, One Action: A function should do exactly what its name suggests, no more. Two independent actions deserve two separate functions.

Functions as Comments

Without Helper Function 

function showPrimes(n) {
  nextPrime: for (let i = 2; i < n; i++) {
    for (let j = 2; j < i; j++) {
      if (i % j == 0) continue nextPrime;
    }
    alert(i); // a prime
  }
}

With Helper Function 

function showPrimes(n) {
  for (let i = 2; i < n; i++) {
    if (!isPrime(i)) continue;
    alert(i); // a prime
  }
}

function isPrime(n) {
  for (let i = 2; i < n; i++) {
    if (n % i == 0) return false;
  }
  return true;
}

Self-Describing Code: The second version is easier to understand because we see a clear action (isPrime) instead of complex logic.
