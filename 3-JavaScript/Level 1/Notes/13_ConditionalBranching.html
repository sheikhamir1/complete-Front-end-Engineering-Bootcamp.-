Why This Matters 💡

Conditional branching is fundamental to programming logic. It allows your code to make decisions and respond differently to varying inputs and situations.

The "if" Statement 🔧

Basic Syntax

The if statement evaluates a condition and executes code if the result is true.

let year = prompt('In which year was ECMAScript-2015 published?', '');

if (year == 2015) {
  alert('You are right!');
}

Code Blocks

Use curly braces {} to group multiple statements:

if (year == 2015) {
  alert("That's correct!");
  alert("You're so smart!");
}

Best Practice

Always use curly braces, even for single statements:

✓ Recommended

if (condition) {
  // code
}

✗ Not Recommended

if (condition)
  // code

Use Cases

  • Input validation
  • Feature toggling
  • Error handling

Boolean Conversion ✅

Truthy & Falsy Values

The if statement converts the condition to a boolean:

Falsy Values

  • • 0
  • • "" (empty string)
  • • null
  • • undefined
  • • NaN
  • • false

Truthy Values

  • • "0" (non-empty string)
  • • " " (whitespace)
  • • [] (empty array)
  • • {} (empty object)
  • • 1 (any non-zero number)
  • • true

Examples

// This code will never execute
if (0) {
  // ...
}

// This code will always execute
if (1) {
  // ...
}

Pre-evaluated Boolean

You can pass a pre-evaluated boolean value:

let cond = (year == 2015); // true or false

if (cond) {
  // code
}

Practical Implications

Understanding truthy/falsy values helps write concise code:

// Instead of this
if (name !== null && name !== undefined && name !== "") {
  // use name
}
// You can write this
if (name) {
  // use name
}

The "else" Clause 🔄

Basic Syntax

The else block executes when the if condition is falsy:

let year = prompt('In which year was ECMAScript-2015 published?', '');

if (year == 2015) {
  alert('You guessed it right!');
} else {
  alert('How can you be so wrong?');
}

Flow Control

The else clause provides an alternative path when the condition fails:

if (condition)
true path
else
false path

Use Cases

  • Error handling and fallbacks
  • Default values
  • Alternative behaviors
  • Validation feedback

Example

function checkAge(age) {
  if (age >= 18) {
    return "Access granted";
  } else {
    return "Access denied";
  }
}

Multiple Conditions: "else if" 🔀

Syntax

Test multiple conditions sequentially:

let year = prompt('In which year was ECMAScript-2015 published?', '');

if (year < 2015) {
  alert('Too early...');
} else if (year > 2015) {
  alert('Too late');
} else {
  alert('Exactly!');
}

Execution Flow

JavaScript checks conditions in order:

  1. First condition is evaluated
  2. If true, its block executes and the rest are skipped
  3. If false, next condition is evaluated
  4. Continues until a condition is true or else is reached

Visual Example

if (year < 2015)
false
continue
else if (year > 2015)
false
continue
else
executes

Practical Use

function getGrade(score) {
  if (score >= 90) {
    return "A";
  } else if (score >= 80) {
    return "B";
  } else if (score >= 70) {
    return "C";
  } else {
    return "F";
  }
}

Conditional Operator '?' ❓

Basic Syntax

The ternary operator is a concise way to assign values based on a condition:

let result = condition ? value1 : value2;

If condition is truthy, returns value1; otherwise, returns value2.

Example

Instead of a full if-else statement:

let accessAllowed;
let age = prompt('How old are you?', '');

if (age > 18) {
  accessAllowed = true;
} else {
  accessAllowed = false;
}
// Using ternary operator
let accessAllowed = (age > 18) ? true : false;

Simplified Form

When the condition itself returns a boolean:

// Instead of this
let accessAllowed = (age > 18) ? true : false;

// You can write this
let accessAllowed = age > 18;

Multiple '?' Operators

Chain ternary operators for multiple conditions:

let age = prompt('age?', 18);

let message = (age < 3) ? 'Hi, baby!' :
  (age < 18) ? 'Hello!' :
  (age < 100) ? 'Greetings!' :
  'What an unusual age!';

This is equivalent to a series of if-else statements.

Non-traditional Use of '?' ⚠️

Using '?' Instead of if

Sometimes the question mark is used as a replacement for if:

let company = prompt('Which company created JavaScript?', '');

(company == 'Netscape') ?
  alert('Right!') : alert('Wrong.');

This executes different code based on the condition.

Why It's Problematic

  • Less readable than if-else
  • Harder to debug
  • Not the intended use of the operator

Recommended Approach

Use if-else for executing different code branches:

let company = prompt('Which company created JavaScript?', '');

if (company == 'Netscape') {
  alert('Right!');
} else {
  alert('Wrong.');
}

Our eyes scan code vertically. Multi-line blocks are easier to understand than long horizontal instructions.

Best Practice

Use the ternary operator for its intended purpose:

✓ Good Use

let accessAllowed = age > 18 ? true : false;

✗ Poor Use

(age > 18) ? alert('Access granted') : alert('Access denied');

Summary & Best Practices ✨

Best Practices

  • Always use curly braces with if statements
  • Use ternary operator for simple value assignments
  • Keep conditions simple and readable
  • Avoid nested ternary operators for complex logic

Common Pitfalls

  • Forgetting that some values are truthy/falsy
  • Using ternary operator for complex code execution
  • Omitting curly braces for single statements
  • Creating overly complex nested conditions

Summary 📝

  • • if statements execute code based on a condition
  • • else provides an alternative path when the condition is false
  • • else if allows testing multiple conditions sequentially
  • • The ternary operator (?) is best for simple value assignments
  • • Use if-else for executing different code branches
