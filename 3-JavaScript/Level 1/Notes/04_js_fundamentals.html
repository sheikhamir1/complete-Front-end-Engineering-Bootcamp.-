⚙️ Functions

Reusable blocks of code that make your programs organized and efficient
functions.js
// Function declaration
function greetUser(name) {
  return `Hello, ${name}! Welcome!`;
}

// Function call
let message = greetUser("Alice");
console.log(message); // "Hello, Alice! Welcome!"

// Arrow function (ES6)
const add = (a, b) => a + b;
console.log(add(5, 3)); // 8
🎯
Parameters
Input values for functions
↩️
Return
Output value from function
🏹

🔄 Loops

🤔 Conditional Logic

Make decisions in your code with if, else, and switch statements
conditionals.js
// If-else statement
let age = 18;

if (age >= 18) {
  console.log("You can vote!");
} else {
  console.log("Too young to vote");
}

// Ternary operator
let status = age >= 18 ? "adult" : "minor";
console.log(status); // "adult"
🎯
if/else

❓

🧮 Operators & Math

Perform calculations and operations with arithmetic and logical operators
operators.js
// Arithmetic operators
let a = 10, b = 3;
console.log(a + b); // 13 (addition)
console.log(a - b); // 7 (subtraction)
console.log(a * b); // 30 (multiplication)
console.log(a / b); // 3.33... (division)
console.log(a % b); // 1 (remainder)

// Comparison operators

console.log(a === b); // false (strict equality)

🚀 Modern JavaScript

Explore ES6+ features that make JavaScript more powerful
modern-js.js
"use strict"; // Enable strict mode

✨ JavaScript Specials

Unique features that make JavaScript special and powerful
specials.js
// Dynamic typing
let value = 42; // number
value = "Hello"; // now it's a string!

// Truthy and falsy values
if ("") console.log("Won't run"); // "" is falsy
if ("hello") console.log("Will run"); // non-empty string is truthy

// Type coercion
console.log("5" + 3); // "53" (string concatenation)
console.log("5" * 3); // 15 (numeric conversion)
🔄
Dynamic Typing
Variables can change types
✅❌
