Why This Matters 💡

Understanding operators is fundamental to writing effective JavaScript code. They form the building blocks of expressions and control how values are manipulated and compared.

Operator Terminology 📚

Operand

What operators are applied to. Also called "arguments".

5 * 2 // 5 and 2 are operands

Unary Operator

An operator with a single operand.

let x = 1;
x = -x; // unary negation
alert(x); // -1

Binary Operator

An operator with two operands.

let x = 1, y = 3;
alert(y - x); // 2, binary minus

Same Symbol, Different Operators

The minus symbol (-) can be both unary and binary.

// Unary negation
let x = -5;

// Binary subtraction
let y = 10 - 5;

Mathematical Operations ➕

Basic Operations

Addition (+) a + b
Subtraction (-) a - b
Multiplication (*) a * b
Division (/) a / b

Advanced Operations

Remainder (%)

Returns the remainder of integer division

alert(5 % 2); // 1
alert(8 % 3); // 2
alert(8 % 4); // 0

Exponentiation (**)

Raises a to the power of b

alert(2 ** 2); // 4
alert(2 ** 3); // 8
alert(4 ** (1/2)); // 2

String Concatenation 🔗

Binary + with Strings

When the binary + is applied to strings, it merges (concatenates) them.

let s = "my" + "string";
alert(s); // mystring

Type Conversion

If any operand is a string, the other is converted to a string too.

alert('1' + 2); // "12"
alert(2 + '1'); // "21"

Complex Examples

alert(2 + 2 + '1'); // "41"

Operators work left to right. First 2+2=4, then 4+'1'="41"

alert('1' + 2 + 2); // "122"

First operand is a string, so all are treated as strings

Other Operators

Other arithmetic operators only work with numbers and convert their operands to numbers.

alert(6 - '2'); // 4
alert('6' / '2'); // 3

Numeric Conversion 🔄

Unary Plus Operator

The unary + converts its operand to a number if it isn't already.

// No effect on numbers
let x = 1;
alert(+x); // 1

// Converts non-numbers
alert(+true); // 1
alert(+""); // 0

Comparison with Number()

The unary + does the same thing as Number(), but is shorter.

alert(+"123"); // 123
alert(Number("123")); // 123

Practical Example

Converting string inputs from forms to numbers for calculations.

let apples = "2";
let oranges = "3";

// Binary plus concatenates
alert(apples + oranges); // "23"
// Convert to numbers first
alert(+apples + +oranges); // 5

Why It Works

Unary operators have higher precedence than binary operators, so they are evaluated first.

+apples + +oranges

// Becomes
2 + 3

// Which equals
5

Operator Precedence ⚖️

What is Precedence?

The order in which operators are executed when an expression has multiple operators.

alert(1 + 2 * 2); // 5
// Multiplication has higher precedence

Overriding with Parentheses

Parentheses can override the default precedence order.

alert((1 + 2) * 2); // 6
// Addition is performed first

Precedence Table (Extract)

Precedence Name Sign
14 unary plus +
13 exponentiation **
12 multiplication *
11 addition +
2 assignment =

Example with Unary +

Unary plus (precedence 14) is higher than binary plus (precedence 11).

alert(+apples + +oranges);

// Unary + first
alert((+apples) + (+oranges));

Assignment Operations 📝

Assignment as an Operator

The assignment = operator returns the assigned value.

let a = 1;
let b = 2;
let c = 3 - (a = b + 1);
alert(a); // 3
alert(c); // 0

Chaining Assignments

Multiple assignments can be chained together.

let a, b, c;
a = b = c = 2 + 2;
alert(a); // 4
alert(b); // 4
alert(c); // 4

Chained assignments evaluate from right to left.

Modify-in-Place Operators

Operators that modify a variable and store the result in it.

let n = 2;
n += 5; // n = n + 5
n *= 2; // n = n * 2
alert(n); // 14

Available for all arithmetic operators: +=, -=, *=, /=, %=, **=

Precedence of Modify Operators

Modify operators have the same precedence as normal assignment.

let n = 2;
n *= 3 + 5;
alert(n); // 16

// Same as
n = n * (3 + 5);

Advanced Operators 🚀

Increment/Decrement

Prefix Form (++counter)

Returns the new value

let counter = 1;
alert(++counter); // 2

Postfix Form (counter++)

Returns the old value

let counter = 1;
alert(counter++); // 1

Bitwise Operators

Treat numbers as 32-bit integers

  • AND ( & )
  • OR ( | )
  • XOR ( ^ )
  • NOT ( ~ )
  • LEFT SHIFT ( << )
  • RIGHT SHIFT ( >> )
  • ZERO-FILL RIGHT SHIFT ( >>> )

Rarely used in web development

Comma Operator

Evaluates multiple expressions, returns the last one

let a = (1 + 2, 3 + 4);
alert(a); // 7

Very low precedence, often used in for loops:

for (a = 1, b = 3, c = a * b; a < 10; a++) {
...
}

Best Practices 💡

  • • Use increment/decrement on separate lines for clarity
  • • Avoid complex expressions with multiple operators
  • • Use parentheses to make precedence explicit

Understanding these operators will help you write more concise and efficient JavaScript code.
