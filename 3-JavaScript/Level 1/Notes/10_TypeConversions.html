Type Conversions

Understanding how JavaScript converts between types

Introduction 🔄

Automatic Conversions

  • • Operators and functions convert values automatically
  • • alert() converts values to strings
  • • Math operations convert values to numbers

Explicit Conversions

  • • Sometimes we need to convert types explicitly
  • • String(), Number(), Boolean() functions
  • • Important for predictable behavior

Key Takeaway 💡

Understanding type conversions is essential for writing predictable JavaScript code and avoiding common bugs.

String Conversion 📝

When It Happens

  • • alert() automatically converts to string
  • • String concatenation with + operator
  • • Explicit conversion with String(value)

Conversion Rules

  • • true → "true"
  • • false → "false"
  • • null → "null"
  • • undefined → "undefined"

Example

let value = true;
alert(typeof value); // boolean

value = String(value); // "true"
alert(typeof value); // string

The boolean value is converted to its string representation

Use Cases

  • • Displaying values to users
  • • Building output strings
  • • Serializing data

Numeric Conversion 🔢

When It Happens

  • • Mathematical operations (+, -, *, /)
  • • Comparison operators (>, <)
  • • Explicit conversion with Number(value)

Conversion Rules

Value Becomes
undefined NaN
null 0
true / false 1 / 0
string Number or NaN

Examples

alert( "6" / "2" ); // 3

let str = "123";
let num = Number(str); // 123
alert(typeof num); // number

let age = Number("invalid");
alert(age); // NaN

Strings are converted to numbers, invalid strings become NaN

String Conversion Details

  • • Whitespace is trimmed
  • • Empty string becomes 0
  • • Non-numeric characters result in NaN

Boolean Conversion ✅

When It Happens

  • • Logical operations (&&, ||, !)
  • • Conditional statements (if, while)
  • • Explicit conversion with Boolean(value)

Conversion Rules

Falsy Values

  • • 0
  • • ""
  • • null
  • • undefined
  • • NaN
  • • false

Truthy Values

  • • "0"
  • • " "
  • • []
  • • {}
  • • 1
  • • true

Examples

alert( Boolean(1) );     // true
alert( Boolean(0) );     // false
alert( Boolean("hello") ); // true
alert( Boolean("") );    // false

Important Note:

The string "0" is truthy in JavaScript, unlike some other languages. 

alert( Boolean("0") );  // true
alert( Boolean(" ") );  // true

Use Cases

  • • Conditional logic
  • • Checking for empty values
  • • Short-circuit evaluation

Rules and Exceptions ⚠️

Common Mistakes

  • undefined becomes NaN as a number, not 0
  • "0" and space-only strings like " " are true as a boolean
  • Forgetting that null becomes 0 in numeric conversion
  • Assuming empty objects are falsy (they're truthy)

Conversion Summary

Original Value String Number Boolean
undefined "undefined" NaN false
null "null" 0 false
true "true" 1 true
false "false" 0 false
"" "" 0 false
"0" "0" 0 true

Remember 🧠

These conversion rules are fundamental to JavaScript. Understanding them helps prevent bugs and write more predictable code.

Code Examples 💻

String Conversion 

// Automatic conversion
alert(true);      // "true"
alert(null);      // "null"

// Explicit conversion
let value = false;
let str = String(value);
alert(str);       // "false"

Numeric Conversion 

// Automatic conversion
alert("5" - 3);   // 2
alert("5" * "2"); // 10

// Explicit conversion
let str = "123";
let num = Number(str);
alert(num);       // 123

// Special cases
alert(Number(null));      // 0
alert(Number(undefined)); // NaN

Boolean Conversion 

// Explicit conversion
alert(Boolean(1));     // true
alert(Boolean(0));     // false
alert(Boolean(""));    // false
alert(Boolean("0"));   // true

// Implicit conversion in conditions
let value = "hello";
if (value) {
  alert("This will run because 'hello' is truthy");
}

// Checking for empty values
let userInput = "";
if (!userInput) {
  alert("Please enter a value");
}

Combined Example 

// A practical example of type conversions
function processInput(input) {
  // Convert to string to ensure it's a string
  const strInput = String(input);
  
  // Check if it's a valid number
  const numInput = Number(strInput);
  
  if (isNaN(numInput)) {
    // Not a valid number
    alert(`"${strInput}" is not a valid number`);
    return null;
  }
  
  // Convert to boolean to check if it's truthy
  const boolInput = Boolean(numInput);
  
  if (boolInput) {
    return numInput * 2;  // Double the number
  } else {
    alert("The number is zero");
    return 0;
  }
}

// Test cases
processInput("5");     // Returns 10
processInput("0");     // Alerts "The number is zero"
processInput("hello"); // Alerts "hello" is not a valid number"

Tips & Best Practices ✨

Best Practices

  • Use explicit conversion for predictable behavior
  • Always validate user input with Number() before math operations
  • Use strict equality (===) to avoid type coercion
  • Be explicit about your intentions in code comments

Common Mistakes

  • Forgetting that "0" is truthy in boolean context
  • Using == instead of === for comparisons
  • Not handling NaN after numeric conversion
  • Assuming undefined converts to 0 in math operations

Pro Tip 🔍

Use modern JavaScript features like optional chaining and nullish coalescing to handle undefined/null values more gracefully. 

// Instead of this
let username = user.name || "Guest";

// Consider this (for null/undefined only)
let username = user.name ?? "Guest";
