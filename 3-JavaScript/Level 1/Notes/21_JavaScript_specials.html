Code Structure 📝 →

⚡
Semicolons in JavaScript 

alert('Hello'); alert('World');

// Usually, a line-break is also treated as a delimiter
alert('Hello')
alert('World')

This is called "automatic semicolon insertion" 🤖

⚠️
When It Doesn't Work 

alert("There will be an error after this message")
[1, 2].forEach(alert) // Error!
💡

Most style guides agree that we should put a semicolon after each statement! 📌

Strict Mode 🔒 →

🛡️
Enabling Modern JavaScript 

// To fully enable all features of modern JavaScript
'use strict';
...
// The directive must be at the top of a script 
// or at the beginning of a function body

Why Use Strict Mode? 🤔

  • Catches common coding errors and throws exceptions 🚨
  • Prevents or throws errors for unsafe actions ⚠️
  • Disables confusing or poorly thought-out features 🚫
✅

With Strict Mode

Modern behavior, better error handling 🚀

⚠️

Without Strict Mode

Old-fashioned "compatible" behavior 👴

Interaction 🖥️ →

💬
Browser Interaction Functions

❓
prompt(question, [default])

Ask a question, return visitor input or null if canceled 

let userName = prompt("Your name?", "Alice");

✅
confirm(question)

Ask a question, return true/false based on selection 

let isTeaWanted = confirm("Do you want some tea?");

📢
alert(message)

Output a message to the user

alert("Visitor: " + userName);

⚠️
Important Note

All these functions are modal - they pause code execution and prevent visitor interaction with the page until answered! ⏸️

Operators ⚙️ →

🔢
Arithmetic 

// Regular: * + - /, % for remainder
// ** for power of a number
let result = 5 ** 2; // 25

Binary plus + concatenates strings! 📝

🔄
Assignments 

// Simple: a = b
// Combined: a *= 2, a += 3, etc.
let x = 5;
x += 3; // x = 8

❓
Conditional 

// Only operator with three parameters
let result = (age > 18) ? "Adult" : "Minor";

🤔
Logical 

// AND &&, OR ||, NOT !
// Short-circuit evaluation
let result = a || b; // First truthy value

🆕
Nullish Coalescing 

// a ?? b: a unless null/undefined
let user = "John";
let name = user ?? "Anonymous";

⚖️
Comparisons 

// == converts types, === doesn't
alert(0 == false);   // true
alert(0 === false);  // false

Loops & Switch 🔄 →

🔄
Types of Loops 

// 1. While loop
while (condition) { ... }

// 2. Do-while loop
do { ... } while (condition);

// 3. For loop
for(let i = 0; i < 10; i++) { ... }

Loop Control 🎮

  • break - Exit the entire loop
  • continue - Exit the current iteration
  • Use labels to break nested loops 🏷️

🔀
Switch Statement 

let age = prompt('Your age?', 18);

switch (age) {
  case "18":
    alert("This works!"); // Uses strict equality (===)
    break;
  default:
    alert("Any value not equal to one above");
}
💡

Switch uses strict equality (===) for comparisons! That's why case 18: didn't work with prompt's string result! 🤔

Functions & Conclusion 🎉 →

⚙️
Ways to Create Functions

1️⃣
Function Declaration 

function sum(a, b) {
  let result = a + b;
  return result;
}

2️⃣
Function Expression 

let sum = function(a, b) {
  let result = a + b;
  return result;
};

3️⃣
Arrow Functions 

// Expression on the right side
let sum = (a, b) => a + b;

// Multi-line with explicit return
let sum = (a, b) => {
  return a + b;
}
