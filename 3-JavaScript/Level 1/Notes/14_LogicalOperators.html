Overview of Logical Operators

What are Logical Operators?

Operators that evaluate expressions to true or false

Can be applied to values of any type, not just boolean

Result can also be of any type

Used in conditional statements and expressions

OR (||) Operator

Basic OR Behavior

In classical programming, returns true if any operand is true

Returns false only if both operands are false

A B A || B
true true true
false true true
true false true
false false false

OR in JavaScript

Operands are converted to boolean for evaluation

Commonly used in if statements to test conditions

let hour = 9;
if (hour < 10 || hour > 18) {
  alert( 'The office is closed.' );
}
let hour = 12;
let isWeekend = true;
if (hour < 10 || hour > 18 || isWeekend) {
  alert( 'The office is closed.' );
}

Short-circuit Evaluation of OR

How OR Works in JavaScript

Evaluates operands from left to right

For each operand, converts to boolean

If result is true, stops and returns original value

If all are falsy, returns the last operand

// Returns the first truthy value
alert( 1 || 0 ); // 1
alert( null || 1 ); // 1
alert( null || 0 || 1 ); // 1
alert( undefined || null || 0 ); // 0

Practical Uses

Getting the first truthy value from a list

let firstName = "";
let lastName = "";
let nickName = "SuperCoder";
alert( firstName || lastName || nickName || "Anonymous"); // SuperCoder

Short-circuit evaluation for performance

true || alert("not printed");
false || alert("printed");
Tip

Use this feature to execute commands only if the condition on the left is falsy

AND (&&) Operator

Basic AND Behavior

Returns true if both operands are truthy

Returns false if any operand is falsy

A B A && B
true true true
false true false
true false false
false false false

AND in JavaScript

Commonly used to test multiple conditions

let hour = 12;
let minute = 30;
if (hour == 12 && minute == 30) {
  alert( 'The time is 12:30' );
}

Any value is allowed as an operand

if (1 && 0) { // evaluated as true && false
  alert( "won't work, because the result is falsy" );
}

Short-circuit Evaluation of AND

How AND Works in JavaScript

Evaluates operands from left to right

For each operand, converts to boolean

If result is false, stops and returns original value

If all are truthy, returns the last operand

// If the first operand is truthy,
// AND returns the second operand:
alert( 1 && 0 ); // 0
alert( 1 && 5 ); // 5

// If the first operand is falsy,
// AND returns it. The second operand is ignored
alert( null && 5 ); // null
alert( 0 && "no matter what" ); // 0

Multiple AND Operations

Returns the first falsy value or the last value

// Several values in a row
alert( 1 && 2 && null && 3 ); // null

// When all values are truthy
alert( 1 && 2 && 3 ); // 3, the last one
Recommended
let x = 1;
if (x > 0) {
  alert( 'Greater than zero!' );
}
Not Recommended
let x = 1;
(x > 0) && alert( 'Greater than zero!' );

NOT (!) Operator

Basic NOT Behavior

Accepts a single argument

Converts operand to boolean type

Returns the inverse value

alert( !true ); // false
alert( !0 ); // true
alert( !"" ); // true
alert( !null ); // true

Double NOT (!!)

Used for converting to boolean

First NOT converts to boolean and inverts

Second NOT inverts it back

alert( !!"non-empty string" ); // true
alert( !!null ); // false

Alternative: Boolean() function

alert( Boolean("non-empty string") ); // true
alert( Boolean(null) ); // false

Operator Precedence

Precedence Order

NOT ! has the highest precedence

AND && has higher precedence than OR ||

OR || has the lowest precedence

Practical Examples

NOT always executes first

let x = true, y = false;
alert( !x && y ); // false
// Equivalent to: (false) && y = false

AND has higher precedence than OR

let a = 1, b = 2, c = 3;
alert( a || b && c ); // 1
// Equivalent to: a || (b && c) = 1 || (true) = 1
Tip

Use parentheses to make your intentions clear and control evaluation order

Summary

OR (||) Operator
  • Returns the first truthy value
  • Returns the last value if all are falsy
  • Uses short-circuit evaluation
  • Useful for fallback values
AND (&&) Operator
  • Returns the first falsy value
  • Returns the last value if all are truthy
  • Uses short-circuit evaluation
  • Useful for multiple conditions
NOT (!) Operator
  • Inverts the boolean value
  • Double NOT (!!) converts to boolean
  • Has the highest precedence
  • Accepts a single argument
Key Takeaways
  • Logical operators work with any data type
  • They return the original value, not just true/false
  • Precedence order: ! > && > ||
  • Use parentheses for clarity

Understanding logical operators is essential for writing effective conditional logic in JavaScript.
