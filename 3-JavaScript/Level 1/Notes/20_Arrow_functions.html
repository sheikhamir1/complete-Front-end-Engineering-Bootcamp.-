Arrow Functions 😊

The Basics of Modern JavaScript Functions ✨

🎯 ES6 💻 JavaScript ⚡ Functions

Introduction 🌟 →

💡

Arrow functions provide a more concise syntax for writing function expressions in JavaScript. 🎯

👨‍💻

They were introduced in ES6 and have become a standard in modern JavaScript development. 🚀

🔥

Arrow functions are not just syntactic sugar - they also have differences in how they handle this. 🤔

🚀

Concise

Shorter syntax for function expressions 📝

🔄

Lexical this

No binding of their own this 🎯

👍

Convenient

Great for callbacks and one-liners ✨

Basic Syntax 📝 →

👴
Traditional Function 

let func = function(arg1, arg2, ..., argN) {
  return expression;
};

✨
Arrow Function 

let func = (arg1, arg2, ..., argN) => expression;
⚠️

The arrow function creates a function that evaluates the expression on the right side and returns its result. 🎯

Single Argument 🎯 →

👉
Parentheses Can Be Omitted 

let double = n => n * 2;
// roughly the same as:
// let double = function(n) { return n * 2; }

alert( double(3) ); // 6
➡️

With a single argument, parentheses can be omitted for even shorter syntax! 🎉

👉

With Parentheses

let square = (x) => x * x;
✅

Without Parentheses 

let square = x => x * x;

No Arguments 🤷‍♂️ →

⚠️
Empty Parentheses Required 

let sayHi = () => alert("Hello!");

sayHi(); // Shows "Hello!"
💡

When there are no arguments, parentheses are empty but they must be present! 📌

✅

Correct

let greet = () => "Hi!";
❌

Incorrect

let greet = => "Hi!"; // Syntax error

Dynamic Creation 🎭 →

🎨
Using Arrow Functions Conditionally 

let age = prompt("What is your age?", 18);
let welcome = (age < 18) ?
  () => alert('Hello!') :
  () => alert("Greetings!");

welcome();

How it works: 🧠

  • Arrow functions can be used in the same way as Function Expressions 🔄
  • They're great for creating functions dynamically based on conditions 🎯
  • The ternary operator selects which arrow function to assign 🎲
🎯

Perfect for Callbacks

Arrow functions are especially useful for callbacks in event handlers, array methods, and more! 🚀

Code Examples 💻 →

📝
Multiline Arrow Functions 

let sum = (a, b) => {  // the curly brace opens a multiline function
  let result = a + b;
  return result; // if we use curly braces, then we need an explicit "return"
};

alert( sum(1, 2) ); // 3
⚠️

When using curly braces for multiline arrow functions, you must explicitly use the return statement to return a value. 📌

🚀
One-liner 

let multiply = (x, y) => x * y;

Implicit return of expression ✨

📋
Multiline 

let multiply = (x, y) => {
  let result = x * y;
  return result;
};

Explicit return required 📝

Best Practices 🎯

Common Mistakes ⚠️

  • ✗
    Forgetting parentheses with no arguments 🤷‍♂️
