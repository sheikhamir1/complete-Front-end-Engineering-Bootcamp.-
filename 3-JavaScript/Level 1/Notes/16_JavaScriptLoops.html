Introduction to Loops 🔄

What are Loops?

  • Reduce code duplication
  • Improve efficiency

Types of Loops We'll Cover

while

Condition checked before each iteration

Condition checked after each iteration

Most common loop with initialization, condition, and increment

The "while" Loop ⏳

Syntax

while (condition) {
  // code to execute
  // "loop body"
}
Condition checked before each iteration
Code runs as long as condition is truthy
Single execution = one iteration

Example

let i = 0;
while (i < 3) {
  alert(i);
  i++;
}
Shows 0, then 1, then 2
Don't forget i++ or loop runs forever!

How It Works

1

Check condition

2

Execute code

3

Repeat if true

The "do...while" Loop 🔄

Syntax

do {
  // code to execute
  // "loop body"
} while (condition);
Condition checked after each iteration
Body always runs at least once
Use when code must run before checking condition

Example

let i = 0;
do {
  alert(i);
  i++;
} while (i < 3);
Shows 0, then 1, then 2
Even if condition is false, body runs once

How It Works

1

Execute code

2

Check condition

3

Repeat if true

Key Difference: Unlike while loops, do...while guarantees at least one execution of the loop body, even if the condition is initially false.

The "for" Loop 🔁

Syntax

for (begin; condition; step) {
  // loop body
}
Most commonly used loop in JavaScript
All loop control in one line
Ideal for counter-based iterations

Example

for (let i = 0; i < 3; i++) {
  alert(i);
}
Shows 0, then 1, then 2
Variable i only visible inside the loop

How It Works

begin

let i = 0

Executes once

condition

i < 3

Checked before each iteration

step

i++

Executes after each iteration

Execution Flow: begin → condition → body → step → condition → body → step → ... until condition is false

Breaking & Continuing Loops ⏭️

The break Statement 

let sum = 0;
while (true) {
  let value = +prompt("Enter a number", '');
  if (!value) break; // Exit the loop
  sum += value;
}
alert('Sum: ' + sum);
Exits the loop immediately
Useful for early termination
Works with all loop types

The continue Statement 

for (let i = 0; i < 10; i++) {
  // Skip even numbers
  if (i % 2 == 0) continue;
  alert(i); // Shows 1, 3, 5, 7, 9
}
Skips current iteration
Jumps to next iteration
Reduces code nesting

Flow Control Comparison

Normal Loop Flow

Check Condition
Execute Body
Update Counter

With break

Check Condition
break → Exit
Not Executed

With continue

Check Condition
continue → Skip
Next Iteration

Remember: break/continue cannot be used with the ternary operator (?) and must be inside a loop.

for Loop

// Find max value in array
const numbers = [5, 12, 8, 130, 44];
let max = numbers[0];
for (let i = 1; i < numbers.length; i++) {
  if (numbers[i] > max) {
    max = numbers[i];
  }
}
alert(`Max: ${max}`);

Practical Use Cases

Searching in Data 

// Linear search with for loop
function findItem(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) {
      return i; // Found at index i
    }
  }
  return -1; // Not found
}

Filtering Data 

// Filter even numbers with while loop
function getEvenNumbers(arr) {
  const result = [];
  let i = 0;
  while (i < arr.length) {
    if (arr[i] % 2 === 0) {
      result.push(arr[i]);
    }
    i++;
  }
  return result;
}

Pro Tip: Choose the right loop for your task - for loops are ideal for known iterations, while loops for unknown iterations, and do...when when you need at least one execution.

Tips & Best Practices 💡

Best Practices

Choose the right loop

Use for for known iterations, while for unknown, do...while when at least one execution is needed

Cache array length

Store length in a variable before looping for better performance

Use meaningful variable names

Instead of i, j, k use descriptive names like index, userIndex, etc.

Common Mistakes

Infinite loops

Forgetting to update the counter or having a condition that never becomes false

Off-by-one errors

Using < instead of <= or vice versa, causing one too many or too few iterations

Modifying collection while iterating

Adding or removing items from an array while looping through it

Performance Tips

Minimize DOM access

Avoid querying the DOM inside loops. Cache DOM references before looping.

Use break/continue wisely

Break early when possible. Continue to skip unnecessary iterations.

Move invariants outside

Place calculations that don't change with each iteration outside the loop.

Code Example: Caching Array Length 

// Instead of this:
for (let i = 0; i < array.length; i++) { ... }

// Do this:
const len = array.length;
for (let i = 0; i < len; i++) { ... }
