Nullish Coalescing Operator

The ?? operator in JavaScript

ES2020
Recent Addition

Introduction 👋

What is it? ❓

The nullish coalescing operator is written as ??

It returns the first argument if it's not null or undefined, otherwise the second one.

Why use it? 🤔

Provides a clean syntax to choose the first "defined" value

Perfect for setting default values when a variable might be null or undefined

result = a ?? b

How It Works ⚙️

The Basic Rule

The result of a ?? b is:

  • If a is defined (not null/undefined), then a
  • If a isn't defined, then b

Equivalent Code

We can rewrite result = a ?? b using existing operators:

result = (a !== null && a !== undefined) ? a : b;

Common Use Case 🎯

Default Values

The most common use case for ?? is to provide a default value:

let user;
alert(user ?? "Anonymous"); // Anonymous (user is undefined)
let user = "John";
alert(user ?? "Anonymous"); // John (user is defined)

Real-World Example 🌍

Display user information with fallbacks:

let firstName = null;
let lastName = null;
let nickName = "Supercoder";

// shows the first defined value:
alert(firstName ?? lastName ?? nickName ?? "Anonymous"); // Supercoder

Comparison with || 🔄

Key Difference

The important difference between || and ?? is:

  • || returns the first truthy value
  • ?? returns the first defined value
Problem with ||
let height = 0;
alert(height || 100); // 100

|| treats 0 as falsy, so it returns 100

Solution with ??
let height = 0;
alert(height ?? 100); // 0

?? checks if height is defined, and it is!

Operator Precedence 📊

Precedence Level

The precedence of ?? is the same as ||

It's evaluated before = and ?, but after most other operations

Precedence: 3 (same as ||)

Use Parentheses!

let height = null;
let width = null;

// important: use parentheses
let area = (height ?? 100) * (width ?? 50);
alert(area); // 5000

Without parentheses, it would evaluate incorrectly!

Code Examples 💻

Basic Usage
let user = {
  name: "John",
  age: 30
};

let city = user.city ?? "Unknown";
alert(city); // "Unknown"
With Functions
function getName(user) {
  return user?.name ?? "Anonymous";
}

alert(getName({ name: "Alice" })); // "Alice"
alert(getName({ age: 25 })); // "Anonymous"
Chaining
let settings = {
  theme: null,
  language: null
};

const theme = settings.theme ?? settings.language ?? "default";
alert(theme); // "default"

Tips & Best Practices 💡

Best Practices

  • Use ?? when you need to check specifically for null or undefined
  • Use parentheses in complex expressions to ensure correct precedence
  • Combine with optional chaining ?. for safe property access

Common Mistakes

  • Using ?? with && or || without parentheses
  • Forgetting that ?? has lower precedence than arithmetic operations
  • Using || when you specifically need to check for null/undefined
Syntax Error Example
// This causes a syntax error!
let x = 1 && 2 ?? 3; // Syntax error

// Use explicit parentheses to fix:
let x = (1 && 2) ?? 3; // Works!

Conclusion 🏁

Key Takeaways

?? provides a short way to choose the first "defined" value

Perfect for assigning default values to variables

Has low precedence - use parentheses in expressions

Can't be used with && or || without parentheses
