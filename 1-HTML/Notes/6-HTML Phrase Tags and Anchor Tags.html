HTML Phrase Tags and Anchor Tags

Adding meaning and navigation to web content

HTML phrase tags are special purpose tags that define the structural meaning of a block of text or the semantics of text. Anchor tags create hyperlinks that allow navigation between web pages and content.

These tags provide semantic meaning to content and enable the interconnected nature of the web through links.

HTML Phrase Tags Overview

Adding semantic meaning to text

HTML phrase tags provide semantic meaning to text content. Following is the list of phrase tags:

  • Abbreviation tag: <abbr>
  • Marked tag: <mark>
  • Strong tag: <strong>
  • Emphasized tag: <em>
  • Definition tag: <dfn>
  • Quoting tag: <blockquote>
  • Short quote tag: <q>
  • Code tag: <code>
  • Keyboard tag: <kbd>
  • Address tag: <address>

These tags provide both visual formatting and semantic meaning, making content more accessible and SEO-friendly.

Abbreviation and Marked Tags

Highlighting and defining terms

Abbreviation Tag: <abbr>

This tag is used to abbreviate a text. To abbreviate a text, write text between <abbr> and </abbr> tags.

<p>
An <abbr title="Hypertext Markup Language">HTML</abbr> language is used to create web pages.
</p>

Marked Tag: <mark>

The content written between <mark> and </mark> tag will show as a yellow mark on the browser. This tag is used to highlight a particular text.

<p>This tag will <mark>highlight</mark> the text.</p>

These tags provide both visual emphasis and semantic meaning to text content.

Strong and Emphasized Tags

Adding importance and emphasis

Strong Tag: <strong>

This tag is used to display the important text of the content. The text written between <strong> and </strong> will be displayed as important text.

<p>In HTML it is recommended to use <strong>lower-case</strong>, while writing a code.</p>

Emphasized Tag: <em>

This tag is used to emphasize the text and display the text in italic form. The text written between <em> and </em> tags will italicized the text.

<p>HTML is an <em>easy </em>to learn language.</p>

These tags provide semantic meaning beyond just visual formatting, making content more accessible.

Definition and Quoting Tags

Defining terms and quoting sources

Definition Tag: <dfn>

When you use the <dfn> and </dfn> tags, it allows you to specify the keyword of the content.

<p><dfn>HTML </dfn> is a markup language.</p>

Quoting Tag: <blockquote>

The HTML <blockquote> element shows that the enclosed content is quoted from another source.

<blockquote cite="https://www.keepinspiring.me/famous-quotes/">
  <p>The first step toward success is taken when you refuse to be a captive of the environment in which you first find yourself.</p>
</blockquote>
<cite>-Mark Caine</cite>

These tags provide semantic meaning to definitions and quotations, improving accessibility and SEO.

Short Quotations and Code Tags

Inline quotes and code snippets

Short Quotations: <q>

An HTML <q> ....... </q> element defines a short quotation. If you will put any content between <q> ....... </q>, then it will enclose the text in double quotes.

<p>Steve Jobs said: <q>If You Are Working On Something That You Really Care About, You Don't Have To Be Pushed. The Vision Pulls You.</q></p>

Code Tag: <code>

The HTML <code> </code> element is used to display the part of computer code. It will display the content in monospaced font.

<p>First Java program</p>
<p><code>class Simple{ public static void main(String args[]){ System.out.println("Hello Java"); }}</code></p>

These tags provide semantic meaning to inline quotes and code snippets.

Keyboard and Address Tags

User input and contact information

Keyboard Tag: <kbd>

In HTML, the keyboard tag <kbd> indicates that a section of content is a user input from the keyboard.

<p>Please press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>t</kbd> to restore page on chrome.</p>

Address Tag: <address>

An HTML <address> tag defines the contact information of the author of the content. The content is written between <address> and </address> tags, and then it will be displayed in italic font.

<address>
You can ask your queries by contact us on <a href="">example123@newdomain.com</a>
<br> You can also visit at: <br>58 S. Garfield Street. Villa Rica, GA 30187.
</address>

These tags provide semantic meaning to user input and contact information.

HTML Anchor Tag

Creating hyperlinks

The anchor tag <a> is an essential HTML element that constitutes a hyperlink, allowing people to navigate among various web pages, files, or parts of a webpage.

It is among the pillars of the web that offer a means of relating content and enables ease of browsing.

What Is Hypertext and a Hyperlink?

It is always beneficial to understand the concept of hypertext, which is the text displayed in a browser that contains hyperlinks, before we delve into the anchor tag itself.

There are hyperlinks, also known as links, which enable users to skip between pages, documents, or even within a single page.

The href attribute is the most important attribute of this tag because it contains the destination of the URL or path.

href Attribute and Linking to Pages

Creating links between pages

href Attribute

The href attribute is used to define the address of the file to be linked. In other words, it directs the user to the destination page.

<a href = "..........."> Link Text </a>

where href represents the attribute that contains the destination address, and Link Text represents the clickable text visible to users.

Linking to another HTML page

<!DOCTYPE html>
<html lang="en">
<head>
  <title>Main Page</title>
</head>
<body>
  <h1>Welcome to the Main Page</h1>
  <p>
    <a href="second.html">Click for Second Page</a>
  </p>
</body>
</html>

This forms a hyperlink that, when activated, opens the given file (second.html) in the same tab by default.

Target Attribute and Link Appearance

Controlling how links open

Target Attribute

If we want to open that link to another page, then we can use the target attribute of <a> tag. With the help of this link, you will be directed to the next page.

<p>Click on <a href="https://www.tpointtech.com/" target="_blank"> this-link </a>to go on home page of Tpoint Tech.</p>

Link Appearance

  • An unvisited link is displayed in blue and underlined.
  • A visited link is displayed underlined and purple.
  • An active link is underlined and red.

Target="_blank" is an instruction that informs the browser to open the link in a new tab without affecting the original one.

Image Links and Email/Phone Links

Creating different types of links

Anchor Tag with Images

Anchor tags do not work only with text; they can also be used to create image links.

<a href="https://www.tpointtech.com/">
  <img src="/tpt-logo.png" alt="main logo of tpointtech" width="170" height="57">
</a>

Email and Telephone Links

Email and phone links can also be an anchor tag, making it easier for your users to reach you personally.

<a href="mailto:prachet@tpointtech.com">Send Email</a>

<a href="tel:+910000000">Call Us</a>

The mailto: scheme opens a mail client and inserts the destination in the address field. The tel: initiates a call through smartphones.

Internal Page Linking and JavaScript

Advanced link techniques

Internal Page Linking

Internal anchors can also be used on the same web page using anchor tags elsewhere on the site.

<a href="#section1">Go to Section 1</a>
...
<h2 id="section1">Welcome to Section 1</h2>

Executing JavaScript with Anchor Tag

With the javascript: protocol, JavaScript code can be executed through anchor tags.

<a href="javascript:alert('Hello, user!');">Click Me</a>

The href="#id" format is used to refer to an element that is located on the same page and has the same id.

Additional Anchor Tag Attributes

More control over link behavior

There are several additional attributes that can be used with anchor tags to control their behavior:

Attribute Description
href Defines where in a link to go
target States where the link has to be opened
download Triggers download instead of navigating
hreflang Declares the language of the referred document
rel Describes the connection between related and source document
media Mentions the device/media to which the resource is optimized
type Defines the type of MIME of the linked content

These attributes provide more control over how links behave and are processed by browsers.

Conclusion

Key takeaways

Phrase Tags

HTML phrase tags are very important in providing semantic luster and precision to web content. They provide both the browser and assistive technologies with the intended meaning and context of the text.

Not only does this enhance accessibility to users with disabilities, but it also makes search engines comprehend the arrangement and importance of the content, thus boosting SEO performance.

Anchor Tags

The HTML anchor tag is a useful tag that enables you to link web pages together, download files with links, and link to emails, phone numbers, or even JavaScript.

Whether it is plain text links, clickable images, or primary internal navigation, the anchor tag is one of the key skills that a web developer needs to master.

Understanding and properly using phrase tags and anchor tags is essential for creating accessible, semantic, and well-connected web content.
