HTML Tags and Attributes

The building blocks of web content

HTML tags are like keywords which defines that how web browser will format and display the content. With the help of tags, a web browser can distinguish between an HTML content and a simple content.

HTML tags contain three main parts: opening tag, content and closing tag. But some HTML tags are unclosed tags.

HTML Tags Syntax and Examples

Understanding tag structure

When a web browser reads an HTML document, browser reads it from top to bottom and left to right. HTML tags are used to create HTML documents and render their properties. Each HTML tags have different properties.

Key Points

  • An HTML file must have some essential tags so that web browser can differentiate between a simple text and HTML text.
  • You can use as many tags you want as per your code requirement.
  • All HTML tags must enclosed within < > these brackets.
  • Every tag in HTML perform different tasks.
  • If you have used an open tag <tag>, then you must use a close tag </tag> (except some tags)

Syntax

<tag> content </tag>

Note: HTML Tags are always written in lowercase letters.

Basic HTML Tag Examples

Common tags you'll use frequently

The basic HTML tags are given below:

<p> Paragraph Tag </p>

<h2> Heading Tag </h2>

<b>Bold Tag</b>

<i>Italic Tag</i>

<u> Underline Tag</u>

Unclosed HTML Tags

Some HTML tags are not closed, for example br and hr.

<br> Tag: br stands for break line, it breaks the line of the code.

<hr> Tag: hr stands for Horizontal Rule. This tag is used to put a line across the webpage.

Unclosed tags are special because they don't need a closing tag. They perform a specific function without containing content.

HTML Attributes

Adding extra information to elements

HTML attributes are keywords found in an opening element tag to give more details about that particular element. CSS is needed to manage how HTML elements behave, look and function.

Every attribute takes the form name="value" and should always be put inside the start tag. Nearly every HTML element can use attributes to let us style, link, add tooltips or include images and videos.

Syntax

<element attribute_name="value">content</element>

Example

<!DOCTYPE html>
<html>
<head>
</head>
<body>
  <h1> This is Style attribute</h1>
  <p style="height: 50px; color: blue">It will add style property in element</p>
  <p style="color: red">It will change the colour of content</p>
</body>
</html>

Every attribute increases the accuracy of both the interpretation and presentation of the element by the browser.

The Title Attribute

Adding tooltips to elements

The title attribute is used as text tooltip in most of the browsers. It display its text when user move the cursor over a link or any text. You can use it with any text or link to show the description about that link or text.

Syntax

With <h1> tag:

<h1 title="This is heading tag">Example of title attribute</h1>

With <p> tag:

<p title="This is paragraph tag">Move the cursor over the heading and paragraph, and you will see a description as a tooltip</p>

Example

<!DOCTYPE html>
<html>
  <head>
  </head>
  <body>
    <h1 title="This is heading tag">Example of title attribute</h1>
    <p title="This is paragraph tag">Move the cursor over the heading and paragraph, and you will see a description as a tooltip</p>
  </body>
</html>

The title attribute is commonly used to display additional info via tooltips, enhancing user guidance without cluttering the interface.

The href Attribute

Creating links in HTML

The href attribute is the main attribute of <a> anchor tag. This attribute gives the link address which is specified in that link. The href attribute provides the hyperlink, and if you leave the link address blank, the page will not be redirected.

Syntax

With link address:

<a href="https://www.tpointtech.com//html-anchor">This is a link</a>

Without link address:

<a href="">This is a link</a>

Output

Clickable text that reloads or stays on the current page.

The href attribute is used for making links. A missing value for the link will stop a redirect from occurring.

Image Attributes

Displaying images on web pages

The src attribute is one of the important and required attributes of the <img> element. It is the source for the image which is required to display on the browser. This attribute can contain images in the same directory or another directory.

The size and alternate information of an image are given by width, height and alt.

Example 1

<img src="whitepeacock.jpg" height="400" width="600">

Note: The above example also has height and width attributes, which define the height and width of an image on the web page.

Example 2 (Absolute URL)

<img src="https://tpointtech.com/images/img10" alt="TPointTech banner logo">

The src marks where the image comes from, width, and height let you give it the right size and using alt provides a text with an alternative to show if the image doesn't display correctly.

The alt Attribute

Improving accessibility and SEO

You use the alt attribute to give an image alternative text if it does not load correctly. A website needs to be easy to navigate for everyone and to be effective with SEO.

Example

<img src="img_typo.jpg" alt="Girl with a jacket">

Output

If the image doesn't load, the text "Girl with a jacket" is displayed.

If an image isn't available, the alt text will be read by a screen reader and shown instead. It allows content to be understood and used by everyone.

Quotes in HTML Attributes

Best practices for attribute values

It is possible to include single as well as double quotes around the attribute values. We suggest that quoting your data as always ensures consistency.

Example with Double Quotes

<a href="https://www.tpointtech.com/"> A link to HTML. </a>

Example with Single Quotes

<a href='https://www.tpointtech.com/'> A link to HTML. </a>

Example Without Quotes (Not Recommended)

<a href=https://www.tpointtech.com/> A link to HTML. </a>

All render correctly, but the last one may break if the value contains spaces. It's best practice to always use quotes around attribute values.

The lang Attribute

Specifying the language of your content

The language of the document is set by the lang attribute within the <html> tag for easier processing by both search engines and tools for those with disabilities.

Example

<!DOCTYPE html>
<html lang="en-US">
<body>
  ...
</body>
</html>

Output

Page with metadata indicating the language is U.S. English.

Specifying the language helps search engines understand your content better and improves accessibility for screen readers and translation tools.

Conclusion

The importance of HTML tags and attributes

Element attributes improve how web content operates, looks and can be used by everyone. They enable developers to use links (href), pictures (src, alt, width, height), style elements (style), add tooltips (title) and say what language the content uses (lang).

Best Practices

  • Lowercase names and quotation marks for values aren't compulsory; however, following these as best practices helps achieve code consistency.
  • Always use alt attributes for images to improve accessibility.
  • Use semantic tags to improve SEO and accessibility.
  • Always quote attribute values to avoid unexpected behavior.

You need to use attributes well to ensure your web pages are organised, easy to access and attractive.
