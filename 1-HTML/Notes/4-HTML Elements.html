HTML Elements

The building blocks of web pages

An HTML document is composed of elements. These elements are responsible for creating web pages and defining content on that webpage. An element in HTML usually consists of a start tag <tag name>, a close tag </tag name>, and content inserted between them.

Technically, an element is a collection of start tags, attributes, end tags, and content between them.

HTML Elements Syntax and Example

Understanding element structure

Syntax

<p> Hello world!!! </p>

Example

<!DOCTYPE html>
<html>
<head>
  <title>WebPage</title>
</head>
<body>
  <h1>This is my first web page</h1>
  <h2> How it looks?</h2>
  <p>It looks Nice!!!!!</p>
</body>
</html>

All the content written between body elements is visible on the web page.

Void Elements

Elements that don't need closing tags

Void elements are HTML elements that do not require a closing tag or content, such as <br> or <img>. Such elements are known as Void elements or empty elements. These elements are also referred to as unpaired tags.

Common Void Elements

  • <br> - Inserts a line break
  • <hr> - Adds a horizontal rule
  • <input>, <link>, and <img> - Provide specific functionalities without the need for content

Example

<p>This is a <br> paragraph with a line break.</p>

Note: Even though browsers can close missing tags, this can cause various problems with page layouts. Always finish off every non-void element with an end tag.

Nested HTML Elements

Elements within elements

HTML can be nested, which means an element can contain another element. This means that HTML makes it possible for elements to be placed within other elements. Creating a hierarchy makes it possible to sort things into order.

Example

<!DOCTYPE html>
<html>
<head>
  <title>HTML Elements</title>
</head>
<body>
  <h1>GeeksforGeeks</h1>
  <p>Computer science portal</p>
</body>
</html>

The <html> element is the root of an HTML document and contains all other elements, including <head> and <body>. The document's elements include an enclosure of <head> and <body> inside the <html>. Both the <h1> and <p> elements are inside <body>.

Block-level and Inline Elements

Two main categories of HTML elements

For the default display and styling purpose in HTML, all the elements are divided into two categories:

  • Block-level Element
  • Inline Element

Block-level Element

HTML pages are built from the basic elements called block-level elements. They arrange the main content on the page by breaking it into helpful and organized sections. Usually, each block element sits alone on a new line and runs the entire width of the page, no matter how wide or narrow the content is.

Inline Element

Without disturbing how content is displayed, inline elements help you highlight and modify different parts of your text. Like how an inline element appears next to its surrounding words and only takes as much space as needed, unlike block-level elements that have a new line.

Understanding the difference between block-level and inline elements is crucial for proper HTML layout and design.

Common Block-level Elements

Elements that create structure

Following are some of the most common block-level elements in HTML:

Element Description
<div> A container element used to group and style content
<p> Defines a paragraph of text
<h1>-<h6> Heading elements from most to least important
<ul>, <ol> Unordered and ordered lists
<form> Defines an HTML form for user input
<table> Creates a table for displaying data
<header>, <footer> Defines header and footer sections
<section>, <article> Defines sections and articles

Block-level elements are flexible and can contain different types of elements inside them, making them perfect for organizing content.

Block-level Elements Example

Seeing block-level elements in action

Example

<!DOCTYPE html>
<html>
<head>
</head>
<body>
  <div style="background-color: lightblue">This is first div</div>
  <div style="background-color: lightgreen">This is second div</div>
  <p style="background-color: pink">This is a block level element</p>
</body>
</html>

Output

In the above example, we have used the <div> tag, which defines a section in a web page and takes the full width of the page. Also, we have used the style attribute, which is used to style the HTML content, and the background color shows that it's a block-level element.

Block-level elements always start on a new line and take up the full width available to them.

Common Inline Elements

Elements that flow with text

Following are some of the most common inline elements in HTML:

Element Description
<a> Creates a hyperlink to another page or location
<span> A generic inline container for phrasing content
<img> Embeds an image in the document
<strong>, <b> Makes text bold
<em>, <i> Makes text italic
<br> Inserts a line break
<input> Creates an input control for forms
<code> Defines a piece of computer code

Inline elements are applied along with block-level elements to make some parts of a web page stand out.

Inline Elements Example

Seeing inline elements in action

Example

<!DOCTYPE html>
<html>
<head>
</head>
<body>
  <a href="https://www.tpointtech.com/html-tutorial">Click on link</a>
  <span style="background-color: lightblue">this is inline element</span>
  <p>This will take the width of the text only</p>
</body>
</html>

Output

Inline elements like <a> and <span> only take up as much width as necessary and flow with the surrounding text.

Inline elements don't start on a new line and only take up as much width as necessary.

Best Practices

Writing clean and maintainable HTML

HTML Best Practices

  • Be sure to close all the tags that have data inside them. Close tags on your own rather than leaving it to any automatic correction from the browser.
  • Tags should always be in lowercase. The lowercase letters in HTML make the code look better and are compatible with XHTML.
  • Pay attention to nesting. An incorrectly built layout can ruin your web pages and make them unrenderable.
  • Use semantic elements like <header>, <nav>, <main>, <article>, <section>, <aside>, and <footer> to give meaning to your content.
  • Always include alt attributes for images to improve accessibility.
  • Use proper heading hierarchy (h1, h2, h3, etc.) for better structure and SEO.
  • Keep your HTML clean and well-indented for better readability.

Following these best practices will make your HTML more maintainable, accessible, and SEO-friendly.

Conclusion

The importance of HTML elements

HTML offers numerous elements that help organize and show content online. Parts of the page such as <div>, <section>, <article>, and headings <h1> to <h6> set its structure and levels, and <p>, <ul>, <table>, and <form> help group text and interactive stuff.

Without disturbing the text's overall rhythm, elements such as <a>, <span>, <img>, <strong>, and <em> are inserted inside these blocks.

Key Takeaways

  • Tags such as <br>, <hr>, and <input> take care of specific tasks on their own, so they do not require a closing tag.
  • When combined, these features are the essential parts that help developers make ordered, useful, and accessible web pages using HTML.
  • It is important to know how to work with block-level and inline elements to design responsive and well-formed websites.

Understanding HTML elements is the foundation of web development. Mastering them will help you create better, more accessible websites.
